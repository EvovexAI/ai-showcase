# EvoFlow 接入排查：系统怪癖 vs 脚本问题的判定与一键接入脚本

日期：2026-10-14

## 结论先行
- **问题主体在脚本/技能包**：`skills/douyin-video-pipeline/` 只有 SKILL.md，无配套脚本；
  技能复制进 `~/.evoflow/.../skills/custom` 后相对路径失效。→ 补齐脚本 + 新建 onboarding 技能。
- **系统侧 3 个怪癖**（不阻塞，已绕开并写入优化意见）：CLI 卡死、技能生效目录不一致、
  扩展注册表在 `.evoflow-dev` 而非文档所述 `.evoflow`。

## 可复用的硬结论（下次直接抄）
1. **UFO = EvoFlow**（用户别称，来源 memory facts）。
2. **技能唯一生效目录**：`~/.evoflow/profiles/default/skills/custom/<name>/`（gateway 实测），
   别只写 `.evoflow-dev`。
3. **扩展注册表**：`~/.evoflow-dev/ui-extensions/registry.json`（folder-link，只记路径）。
4. **知识库（owned Vault）**：venv 服务管理，gateway `/api/knowledge/{dataset_id}` 是另一套（dataset 为空）；
   AI 的 `knowledge` 工具走 owned Vault。
5. **venv python**（`D:\dev\github\EvoFlow\backend\.venv\Scripts\python.exe`）启动极慢/偶发挂起，
   **根因疑似残留 python 进程堆积**——先 `Stop-Process` 清掉僵尸进程再跑就正常。
6. **PowerShell 5.1 中文脚本必须存 UTF-8 with BOM**，否则中文被当 ANSI 解析报语法错。
7. **ConvertFrom-Json 返回已是数组**，再套 `@()` 会变成 1 元素嵌套数组（`$arr[0]` 是数组不是对象）。
8. **标量取 `$cands[0]` 返回首字符**——要先 `@($cands)[0]`。
