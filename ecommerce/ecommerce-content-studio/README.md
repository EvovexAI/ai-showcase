# 商策造物 · 电商智能创作中枢

面向单品项目的全栈电商内容生产应用。支持商品多视角素材、公开网页检索、卖点/痛点洞察、多平台主图、SKU 套图、详情页、主图视频、操作视频、营销视频、违禁词初筛和成果管理。

## 启动

```powershell
npm install
npm run dev
```

开发地址为 `http://localhost:5173`。生产构建与启动：

```powershell
npm run build
npm start
```

生产地址为 `http://localhost:8787`。

## 生成链路

- 图片与视频模型目录均由 BOLI CLI 实时读取。
- 每次生成都先返回精确报价；报价不扣费。
- 用户必须在报价弹窗中确认当前报价，服务端才会提交。
- 报价记录、幂等键、参数和任务结果保存在 `data/db.json`。
- 超时或状态未知时，只查询原任务，不自动换模型或重复提交。
- 本地上传的图片若要作为远端模型参考图，需要把应用部署到公网，并在“模型与配置”中填写公网素材基础地址；也可以直接添加公网图片 URL。
- 当前 BOLI 视频能力为文生视频。应用不会绕过 CLI 冒充图生视频；项目素材用于洞察、脚本和创意策划。

## 模型配置

全网检索无需额外密钥。若希望用外部推理模型对检索证据做进一步总结，可在“模型与配置”中填写任意 OpenAI Compatible 服务地址、模型名和 API Key。密钥只保存在本机服务端数据文件中，不进入浏览器构建产物或日志。

## 质量检查

```powershell
npm run check
```

该命令会检查 Node 服务端语法并执行完整前端生产构建。
