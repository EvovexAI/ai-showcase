# 陪练师上手笔记（演示资料）

> 这份资料讲的是：**学员怎么用陪练师把一份资料变成自己的知识**。可用于 1009 首跑演示。

## 1. 陪练是什么，不是什么

- 是：把资料拆成 5～12 个可练的节点，短问答一轮一轮过，记录掌握度。
- 不是：讲师后台、班级管理、自动判分引擎，也不替学员总结整本书。
- 学员自己答，陪练师只纠偏；答错一次不算失败，只把档位标成「练习中」。

## 2. 一次完整陪练的四个动作

1. **投料**：把一份资料放进 `data/materials/` 或面板上传；格式优先 Markdown。
2. **梳纲**：让陪练师按资料出大纲——每节要有「学完应能…」的目标和建议练法。
3. **陪练**：每轮只问 1～3 个短问题，学员先答，陪练师再纠正。
4. **回写**：一轮结束写会话摘要，更新掌握度、薄弱点和下一节重点（next_focus）。

## 3. 掌握度三档怎么判

- `unseen` 未学：还没进这一节。
- `practicing` 练习中：能用自己话讲出来，但换个案例会卡。
- `mastered` 已掌握：能复述要点 + 举一个自己的例子 + 指出常见坑。

判断标准是「能不能迁移」，不是「有没有看完」。

## 4. 薄弱的处理方式

薄弱点不删，只标记；下次陪练开始优先热身薄弱点，再进新节点。
一轮里最多记 3 个薄弱点，写多了就失去焦点。

## 5. 常见坑

- 一次灌一整章 → 记不住；应该拆成 2～3 轮。
- 只读不答 → 掌握度会虚高；必须让学员先输出。
- 资料是图片 → 知识库默认不索引图片，需要先把图意写成 Markdown 笔记再入库。
- 进度百分比只是加权显示，不能代替掌握度档位。

## 6. 资料边界

知识库「陪练资料库」负责检索，本地 `data/` 是进度真源；两者冲突时以 `data/` 为准。
