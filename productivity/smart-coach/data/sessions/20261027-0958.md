# 第二轮陪练 · 梳大纲与掌握度判定

热身题（薄弱点·百分比≠掌握度）：学员答——百分比只是加权展示，掌握度要按「能不能迁移」分 unseen/practicing/mastered。回答正确，薄弱点复述准确。

n3 梳大纲：要求学员从资料挑 2 个主题各写一条节点目标。学员给出「陪练是什么/不是什么」「掌握度三档」两节，目标写成「学完应能…」，格式正确；建议练法漏写，已纠偏：每节必须带 goal + practice_hint，且节点数控制在 5～12。

n4 掌握度三档：用三个场景判档（讲得出但换案例卡住 → practicing；能复述+自举例+指出坑 → mastered；未进章节 → unseen），学员三档判断全对，但初答用「看过没」作标准，经提醒改为「能不能迁移」。

掌握度：n3=practicing（能写目标，练法仍缺），n4=practicing（判档正确，标准需再固化）。薄弱点保留：把进度百分比当掌握度。下轮进 n5 弱点记录与热身 + n6 常见坑自查。
