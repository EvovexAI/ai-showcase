# 第三轮陪练 · 薄弱点热身与常见坑自查

自主练一轮（学员未在线，按 coach-system 自答演示，供下轮真人核对）。

n5 热身（薄弱点·百分比≠掌握度）：自答——百分比是节点加权后的展示值，掌握度只看能不能迁移：讲得出但换案例卡 = practicing；能复述+自举例+点坑 = mastered。

n5 弱点记录：(1) 薄弱点是内容层，不删只标记，下次先热身再进新节点；(2) 一轮最多记 3 个，超过就失去焦点、下轮热身做不完；(3) 若一轮记 6 个 → 热身变灌输，学员只记得压力不记得要点。

n6 常见坑自查自答 4 个：一次灌一整章、只读不答（掌握度虚高）、图片没转 Markdown 笔记就入库（检索不到）、把百分比当掌握度。补充：资料与 data/ 冲突时以 data/ 为准（n7 预告）。

掌握度：n5 = practicing（要点讲对，还需在真实一轮里按 3 个上限实操一次）；n6 = practicing（能列 4 个坑，缺「从错误对话里指认」的练习）。薄弱点不变。
