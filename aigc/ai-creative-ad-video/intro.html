01

项目定位

它是什么、不是什么，一句话说清边界。

这是一条跑通的「一句话 → 成片」CLI 流水线：把小云雀官方 CLI 的操作、创意广告提示词套路、积分消耗策略全部封装成脚本和文档。按套路写一句需求，先出 480p 样片确认创意，再花积分转 1080p 成片——省积分，也省返工。

#广告视频#小云雀 CLI#提示词套路库#样片确认制#积分策略

交付物

  • 1080p 创意广告成片（本地下载）
  • 创意提示词套路库（prompts/）
  • PowerShell 参数化封装脚本
  • CLI 安装/登录/积分策略文档
02

目标

做这个项目想达成什么，按「给谁省什么」来写。

门槛从「会拍会剪」降到「会打字」

一句话 + 套路库，出一条可投放的广告片。

积分花在刀刃上

先 480p 样片确认创意，避免 1080p 白烧积分。

套路可沉淀

每条好广告的提示词都进套路库，越攒越准。

日常怎么用

单开网页只是「手动挡」。接入 EvoFlow 后，同一个能力有四种发起方式，外加一条沉淀闭环。

工作台对话发起

在 EvoFlow 对话框直接 @员工 甩一条任务，员工调起本台技能，广告成片与提示词直接回进对话。

手机 IM 发起

员工接入飞书 / 钉钉 / 微信等渠道后，手机发消息即可发起——通勤路上顺手一发，出一条广告样片就跑完了。

自动化定时发起

把「出一条广告样片」挂成自动化任务：按计划自动执行，结果准时出现在对话和面板里。

EvoFlow 面板直看

本台 UI 以扩展面板嵌进 EvoFlow，不切窗口，对话和操作台同屏。

沉淀闭环：越用越聪明关键不在跑一次，而在产出落进知识库，反哺之后的每一次发起

发起对话 / IM / 自动化任一入口把任务丢给员工
执行员工调本台技能流水线跑完，产出广告成片与提示词
沉淀报告进知识库广告创意库（建议命名）自动归档、可检索
复用员工查库再生成下次同类任务先查历史产出，结论更准
复用的结论又变成下一次发起的输入 —— 知识库越厚，建议越准
EvoFlow 接入本项目尚未注册 EvoFlow 资产——用 evoflow-onboarding-kit 一键接入：注册扩展面板 → 同步知识库 → 雇佣员工，四个脚本一条龙（已在拆解台 / 博主分析器打样）。
07

小白怎么上手

不写代码，三步跑通第一条产出。

开始前确认（一次性准备）开通小云雀会员的账号；Node.js 22+；首次运行 npx @pippit-dev/cli@latest install 安装 CLI 并 pippit-tool-cli login 浏览器授权登录。
1

安装并登录 CLI

确认 logged_in 为 true，账号必须是开通会员的那个。

# 安装（已装可跳过） npx @pippit-dev/cli@latest install pippit-tool-cli login pippit-tool-cli status # ✓ logged_in: true
2

查积分，写需求出样片

先查余额心里有数；把广告需求按套路库写好，跑封装脚本出 480p 样片。

# 查积分 → 一键生成 pippit-tool-cli get-credit-balance powershell -File scripts/generate-ad.ps1 -Prompt "你的广告创意"
3

确认样片，转 1080p 成片

样片满意再转 1080p，成片自动下载到本地。

常见问题

提示登录失效 / 401？
会员账号才有效；重新 pippit-tool-cli login，确认浏览器授权完成。
积分不够怎么办？
先出 480p 样片控制消耗；删减镜头数也能省积分。
生成的视频能商用吗？
以小云雀平台的服务条款为准；投放前自行确认素材版权合规。

想自己做一个？0→1 提示词

把下面整段喂给 AI 编程助手（ZCode / Cursor 等）。蓝色填空是你要替换的部分。

从 0 到 1 建项目提示词替换蓝色填空 → 整段复制 → 发给 AI
# ── 角色与目标 ── 你是资深全栈工程师。请帮我从零开发一个本地工具：【小云雀 CLI 创意广告流水线——一句话需求 → 480p 样片确认 → 1080p 成片下载】。 # ── 核心用户与场景 ── 主要用户是【电商卖家与投放操盘手】，他们在【要快速产出可投放的广告创意素材】的场景下使用，期望得到【一条 1080p 广告成片 + 可复用的提示词套路】。 # ── 功能清单（MVP）── 1. 封装小云雀官方 CLI 的安装/登录/状态检查 2. 按提示词套路库组织需求，生成 480p 样片 3. 样片确认后转 1080p 并自动下载 4. 积分查询与消耗策略（先样片后成片） # ── 技术约束 ── - 技术栈：【@pippit-dev/cli（Node）+ PowerShell 封装脚本】 - 全部本地运行，不依赖云服务；密钥走环境变量，代码里绝不硬编码 - 端口 【—（CLI 工作流，无端口）】，启动方式：【powershell -File scripts/generate-ad.ps1】 - 关键步骤有实时进度提示；失败要给可读的中文报错 # ── 质量要求 ── - 先给我目录结构和关键模块设计，我确认后再写代码 - 附 README（安装、启动、常见问题），按项目规范不硬编码任何密钥与内网地址 - 边界情况都要有兜底提示，宁可报错清晰也不静默失败
填空技巧「解决什么问题」越具体，AI 一次做对的概率越高。写「给人看报告」不如写「给新手照抄结构」。
小步快跑先让 MVP 跑通再迭代功能；一次让 AI 做十个小功能，不如三轮各做三个。
安全红线永远在提示词里写明「密钥走环境变量」——这是本系列所有项目的铁律。
验收标准把「先出设计再写码」「失败要中文报错」写进提示词，能有效防住糊弄式实现。
