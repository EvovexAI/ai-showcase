# AI 生创意广告视频（小云雀 CLI 工作流）

把"一个广告主题"变成"一支可投放的广告视频"，全流程基于小云雀官方 CLI，先预览样片再出成片，控制积分消耗。

## 何时使用

- 用户要给抖音/小红书/电商做一个创意广告短片（生硬需求 → 提炼成可执行的镜头语言 prompt）
- 用户给了广告主题、产品或风格方向，需要出片
- 用户要求"用 AI 做广告视频 / 创意广告 / 卡点广告"

## 执行流程

1. **定创意**：从 [创意广告套路库](../prompts/创意广告套路库.md) 选套路（无厘头 / 卡点 / 镜头穿梭 / 拼接融合 / 神转折 / 魔性抽象），写成 3~5 句镜头语言 prompt：场景 → 动作 → 镜头运动 → 节奏 → 收尾。
2. **查环境**：`ensure-cli.ps1` 确认 CLI 已装、已登录（未登录走 `pippit-tool-cli login` 浏览器授权，**账号必须是开通会员/有积分的那个**）。
3. **查模型/积分**：`pippit-tool-cli model list` 选模型（综合最强 `Seedance_2.5`；省钱预览 `Seedance_2.5_draft`）；`get-credit-balance` 看余额。
4. **出样片（省钱关键）**：用 `Seedance_2.5_draft --draft` 提交，拿 thread_id/run_id，`query-result` 下载 480p 样片给用户预览。
5. **确认后转成片**：用户认可后 `draft-to-final.ps1 -DraftTaskId <draft_task_id>`，出 1080p 成片并交付。
6. **交付**：视频通过媒体渲染/文件交付展示；附 thread link、成本、下次优化点。

## 参数要点

| 参数 | 说明 |
|---|---|
| `--model` | 必填，取 `model list` 的准确 key；用户指定才用，否则默认 Seedance 2.5 系列 |
| `--duration` | 整数秒；Seedance 2.5 常规模式 4–30；广告常见 5/10/15 |
| `--ratio` | `9:16`（抖音竖屏）/ `16:9`（横屏）/ `1:1` / `4:3` 等 |
| `--resolution` | `720p` / `1080p` 等；Draft 两阶段服务端固定（样片 480p、成片 1080p） |
| `--generate-type 1` | 首尾帧模式：首帧、尾帧顺序传两次 `--image` |
| `--task-type` | `reference`（参考生成）/ `edit`（编辑）/ `extend`（延长） |
| `--audio` | 传 BGM 做卡点节奏参考（仅 `.mp3/.wav`） |
| `--seed` | 固定种子，系列广告保持画面风格一致 |
| `--source` | 宿主来源统计，豆包办公填 `doubao_office` |

## 创意广告 prompt 写法

- 用**镜头语言**而非描述性文案：说清"机位/运动/节奏/转场/色调"，AI 视频模型吃这个
- 卡点广告：给 BGM（`--audio`）+ 提示"卡点节奏快速切换"
- 无厘头：夸张动作 + 荒诞元素（"快递盒里涌出彩色气球"）
- 镜头穿梭：明确起点→途经→终点（"从手机屏幕冲出，掠过键盘、咖啡杯，拉回全景"）
- 少让模型直接生成文字（中文渲染易翻车），文字用后期叠加

## 积分成本（实测口径）

- Seedance 2.5 · 10 秒 · 720p ≈ **200 积分/支**
- 480p 样片更便宜；成片 1080p 单独计费；超分 `video-super-resolution` 另行计费
- 策略：**脚本定稿再出片，样片确认再转成片**，避免废片

## 能力边界

- 不做多轮会话续写/自动拆剧本分镜编排成片（官方 CLI 无此能力）；复杂剧情先人工定稿脚本
- 素材单文件 < 500 MB；图片 jpg/jpeg/png/gif/bmp/webp/svg，视频 mp4/avi/mov/wmv/flv/webm/mkv/m4v，音频 mp3/wav
- 视频生成是异步任务，必须轮询 `query-result` 直到 `completed=true`
