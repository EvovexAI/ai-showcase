# 创意广告套路库（小云雀 Seedance 提示词模板）

基于抖音/网络热门创意广告调研沉淀（2026-10 检索）：卡点、无厘头、镜头穿梭、拼接融合、神转折、魔性抽象等套路，每条附可直接套用的镜头语言 prompt 模板。

> 写法总纲：**用镜头语言，不用描述性文案**。说清 场景 → 主体动作 → 镜头运动 → 节奏 → 色调 → 收尾。少让模型直接生成中文文字（易翻车），文字后期叠加。

---

## 套路 1：无厘头 + 神转折（最易出爆款）

**原理**：开头荒诞夸张、完全看不出卖什么，最后一拍神转折揭晓，制造"啊哈"记忆点。
**案例参考**：泰国"拆弹变电饭煲"广告、美团魔改《为什么追我》急支糖浆广告。

```text
【开头·无厘头】{场景}，{主体}正在{夸张动作}，气氛紧张荒诞，细节夸张搞笑。
【发展·悬念】镜头紧贴{关键元素}，节奏越来越快，悬念拉满。
【转折】突然{神转折动作/元素出现}，画风一转，轻松明快。
【收尾】{产品/服务}亮出，画面定格，暖色调，幽默成就感。
```

**套用示例**（灵感主题）：
> 深夜书房，灵感化作一团发光的能量球在空气中旋转，奇幻无厘头。镜头从能量球内部冲出，穿梭掠过书页、草稿纸、屏幕，卡点切换，流光四溢。镜头拉回，能量球落入画板化作一幅完整作品，画面定格，温暖明亮。

## 套路 2：卡点 / 踩点（配 BGM 效果翻倍）

**原理**：镜头切换严格踩音乐节拍，节奏感强、完播率高（案例：拍立得卡点广告、方便面卡点广告）。
**参数**：`--audio bgm.mp3` 传节奏音乐；prompt 里写明"卡点节奏快速切换"。

```text
【节奏】画面随音乐节拍快速切换，每拍一个镜头，节奏精准。
【镜头】{镜头1 特写} → {镜头2 快切} → {镜头3 全景}，切换干脆利落。
【风格】高饱和、强对比、动感模糊，视觉冲击。
【收尾】最后一拍定格{产品/主体}，画面停住，余韵。
```

## 套路 3：镜头穿梭 / 飞来飞去（视觉炫技）

**原理**：一个连续运镜穿过多个空间/物体，制造"飞"的沉浸感。
**写法关键**：明确 **起点 → 途经 → 终点** 三段。

```text
【起点】镜头从{极小物体特写}开始（如咖啡杯、手机屏幕、钥匙孔）。
【穿梭】镜头猛然冲出，高速掠过{物体A}、{物体B}、{物体C}，空间连续穿越，动态模糊。
【终点】镜头落回{主体/场景}，拉成全景，画面稳定。
```

---

## 套路 4：拼接 / 融合两个世界

**原理**：把两个看似无关的世界 90° 拼接/旋转融合（案例："万物皆有链接" 60 秒拼接广告）。

```text
【A 世界】{世界A}：{主体A}正在{动作A}，色调{色A}。
【B 世界】{世界B}：{主体B}正在{动作B}，色调{色B}。
【融合】镜头 90° 旋转/翻转，两个世界在交界处无缝拼接，边缘发光。
【揭示】拼合后构成{全新意象}，寓意{主题}。
```

---

## 套路 5：魔性抽象（不给思考时间）

**原理**：快速剪辑 + 高饱和 + 魔性动作反复，让观众来不及想"合不合理"（案例：马年抽象广告潮、抖音魔性广告）。

```text
【循环】{主体}反复做{一个魔性动作}，动作循环出现，越来越快。
【冲击】高饱和色彩、闪烁切换、大特写怼脸，视觉轰炸。
【定格】突然静止，反差收尾，出{产品}。
```

---

## 套路 6：粗糙感 / 伪 vlog（消解商业感）

**原理**：故意手机 vlog 画质、随意剪辑，反衬真实（案例：转转"癫"广告）。
**适用**：品牌自黑、年轻化、接地气路线。

```text
【质感】手持拍摄感，轻微晃动，像素感，像随手拍的 vlog。
【对白】路人/主角随意吐槽{话题}，答案汇总成{结论}。
【收尾】结论大字贴出{产品/主张}，粗糙但真诚。
```

## 广告时长建议

| 时长 | 适用 | 积分参考（Seedance 2.5 720p） |
|---|---|---|
| 5 秒 | 品牌记忆点/贴片 | 约 100 |
| 10 秒 | 抖音信息流标准 | 约 200 |
| 15 秒 | 剧情广告/卡点长版 | 约 300 |

## 系列化建议

- 同一系列广告固定 `--seed`，保持主角/色调/运镜一致；
- 首尾帧（`--generate-type 1`）控制"悬念开头 + 品牌收尾"两个关键画面；
- 先出 480p 样片确认节奏，再转 1080p 成片（省积分）。
