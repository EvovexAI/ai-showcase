# 题材资料库（跨项目共享，持久积累）

**用途**：导演每次调研一个题材，结果沉淀到这里。下次同题材直接复用，不再重查。

## 结构

```
library/
├── README.md                    本文件
├── _index.md                    ★总索引：题材 → 文件 → 最后更新 → 用过的项目
└── genres/
    └── <题材词>/
        ├── research.md          七维度调研报告（爆款开头/高潮/反转/爽点/钩子/共同点/子型）
        ├── metric-ruler.md      可数指标表（能直接量剧本）
        └── feature-library.md   招式库（每条带出处剧名）
```

## 三条规则

1. **先查库再出门**。开工第一步先读 `_index.md`，有同题材就直接用。
2. **出门回来必写库**。查到新东西就更新对应文件，并在 `_index.md` 记一行。
3. **过时必标**。超过 90 天没更新的题材，用前要复查一次（赛道会变）。

## 为什么要建这个

材料里的原话：

> 我的流程里有"建尺子"，但尺子只从"当次拿到的那一两部标杆"里长出来 —— 用完就锁死，再没出过门。

反过来说，如果每次出门的结果都不沉淀，就是**反复掏同一份学费**。
