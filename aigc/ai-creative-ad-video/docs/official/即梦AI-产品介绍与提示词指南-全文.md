# 即梦AI 产品介绍与提示词指南（全文）

来源：<https://www.volcengine.com/docs/85621/1834143>（火山引擎·即梦AI，2025.12 更新）
> 官方原文摘录整理。该文以 OmniHuman1.5 数字人为主，但提示词原则对视频生成通用；模型专属细节以 Seedance 2.5 手册为准。

## 1. 产品简介

OmniHuman1.5（即梦同源数字人模型）：单张图片 + 音频 → 视频。支持任意画幅（人物/宠物/动漫等），情绪、动作与音频强关联，可用提示词调整画面、动作、运镜。对比上一代：运动自然度、结构稳定性、主体运动表现力与画质更优。适用：剧情对话、多人对话/对唱、商品交互、漫剧等。

## 2. 提示词指南

### 2.1 核心原则

1. **把编写提示词当成讲故事**：连贯自然的自然语言，减少孤立词汇堆砌
2. **只描述动态的事件**：图片中已包含的静态特征（衣服、首饰）无需描述
3. **清晰、不矛盾、少否定**：具体而非抽象，分步骤引导

### 2.2 最佳实践模板

```
镜头运动 + 说话角色情绪 + 说话状态（说话/哭泣/唱歌/…） + 具体动作 +（可选）背景事件/其他角色的动作
```

完整示例："镜头从侧面缓慢推进到正面中景。年轻女子坐在窗边，心情平静，轻轻端起咖啡杯，微笑着对镜头说话。旁边的男孩悄悄看着她，时不时转向镜头笑笑。背景中灯光柔和地闪烁。"

### 2.3 指令类型与编写技巧（官方示例表）

| 想控制 | 技巧 | 示例 |
|---|---|---|
| 连续动作及走位 | "先、然后"描述动作顺序；加入"说话/唱歌"类词汇 | "镜头跟随，男人转过身看向镜头向前走，陶醉地唱歌。他先用双手摸领口，然后双手张开抬起头，沉醉的样子" |
| 动作与说话次序 | 说话前后可插入动作编排 | "男人迅速摘下口中的香烟，然后对着镜头开口说话" |
| 多角色动作 | 着重描述角色间互动方式；指定说话人需主体检测（mask_url） | "画面左侧举着火把的男人先一边看向其他人说话，随后他重新看向镜头" |
| 镜头运动 | 描述**运镜结束时的镜头状态**可精准控制快慢与结束位置；加"迅速"提高运镜响应率 | "镜头向右环绕，聚焦到男人的脸正面" |
| 情绪层次/微表情 | 结合音频内容描述细腻情绪变化 | "男人先是神情淡定，随后突然变得紧张惊慌，眉头紧皱" |
| 无中生有/增加元素 | 参考图里没有的元素用提示词添加 | "父子神情惊愕望向镜头，镜头推进，空气扭曲波动，父子如尘烟般被抽入画面深处" |
| 镜头焦点控制 | 前后景不同角色，控制移焦 | "记者对着镜头报道，身后的国王突然倒地，镜头对焦到倒地的国王" |
| 环境互动 | 让角色与环境自然互动，或描述背景事件 | "猩猩举起右臂保持自拍姿势看着镜头说话，身后火山岩浆逐渐变成蓝色" |

### 2.4 注意事项（官方）

**推荐做法**
- prompt 写"角色 xxx 说话/唱歌"有助于提高说话表现
- 视频清晰度高度依赖**输入图片清晰度**，尽量上传高清图
- 单次生成有随机性，复杂场景**多次抽卡**
- 输入提示词效果不佳，可尝试**不输 prompt**（纯素材驱动）

**效果规避**
- 结构稳定性 15 秒以内较好，15 秒后可能衰退
- 人脸占比过小偶现口型不动，规避超远景
- 人物长时间出镜再入镜易一致性变化，规避角色反复出镜
- 极端姿势或角度效果可能不佳

## 3. 入参与出参（OmniHuman1.5）

- 入参：图片（JPG/PNG/JFIF，<5MB，<4096×4096，越清晰越好）+ 音频（<35 秒）+ Prompt（可选，支持中英日韩墨西哥印尼语）
- 出参：mp4，1080P
- 计费：1 元/秒（API 单价）
