# Seedance 2.5 官方手册要点（核心提炼）

来源：[https://www.xiaoyunque.com/tutorials/seedance-2-5](https://www.xiaoyunque.com/tutorials/seedance-2-5)（小云雀官方教程中心，2026-10 核对）

适用：小云雀 Web/App + CLI（`generate-video --model Seedance_2.5`），广告 / 短剧 / 商品视频 / 爆款复刻 / 多角色场景

## 一、模型定位与能力（一句话版）



| 维度   | 要点                                                                   |
| ---- | -------------------------------------------------------------------- |
| 核心定位 | 面向「长视频、强参考、可编辑、可控分镜」，更适合短剧、广告、商品视频、爆款复刻、多角色场景                        |
| 单次时长 | 4–30 秒直出（减少 15s + 延长 的拼接感），可继续延长                                     |
| 参考素材 | 最多 30 图 + 10 视频 + 10 音频（总 50 份），同时控制角色 / 场景 / 动作 / 镜头 / 风格 / 道具 / 节奏 |
| 真人感  | 光、镜头运动、表达更接近实拍，AI 感大幅减弱                                              |
| 时间戳  | 秒级可控：按时间段写分镜，指定秒数执行指定画面                                              |
| 分镜   | 多宫格分镜 / 故事板参考，一张图控制多段剧情走向                                            |

## 二、素材输入上限与稳定性建议（官方表）



| 场景       | 官方建议                                                |
| -------- | --------------------------------------------------- |
| 输入总上限    | 图 ≤30 张（4K 内）；视频 ≤10 段（总时长 ≤30s）；音频 ≤10 段（总时长 ≤30s） |
| 主体音视频数量  | 1–5 个效果较好；6–10 个可尝试，稳定性下降需抽卡                        |
| 主体音视频时长  | 5–10s 效果较好；更长稳定性下降                                  |
| 主体图数量    | 1–8 个较好；9–12 个可尝试，稳定性下降                             |
| 多视角主体图   | >5 主体用「单视图」更稳；多视图建议拆成多张图（多图多视图 > 单图多视图）             |
| 视频编辑输入长度 | ≤20s 较好                                             |
| 视频参考图编辑  | 1–5 张较好；6–8 张可尝试                                    |

> **素材不是越多越好，越清楚越好。**
>
>  多素材时 prompt 必须写清 "谁参考谁、参考什么、不参考什么"。

## 三、多模态素材分工（官方表）



| 素材   | 适合参考            | Prompt 写法示例                  |
| ---- | --------------- | ---------------------------- |
| 角色图  | 脸、发型、服装、体型、妆造   | "@图片 1 是主角外观，请保持人物一致"        |
| 商品图  | 包装、材质、颜色、结构细节   | "@图片 2 是商品，请保持包装和 logo 位置不变" |
| 场景图  | 空间、色调、光影、构图     | "@图片 3 参考室内布景和暖色灯光"          |
| 参考视频 | 动作、运镜、剪辑节奏、特效形式 | "@视频 1 只参考打斗动作和镜头节奏，不参考人物外观" |
| 音频   | 节奏、氛围、音效、口播节拍   | "@音频 1 参考鼓点节奏，画面切换跟随节拍"      |

## 四、时间戳控制（2.5 核心可控能力）

**三种写法（官方）**：



| 类型            | 示例                                                     |
| ------------- | ------------------------------------------------------ |
| 时间区间（推荐，注意连续） | "0-3 秒……3-7 秒……7-15 秒"；"\[1s-4s]……\[4s-8s]……\[8s-12s]" |
| 时间点           | "第 5s 快速向左横移转场"、"第 2 秒一道金雷能量自画面顶部破空直落"                 |
| 相对时间          | "张三呆滞站在原地，3 秒后周围的人纷纷摇头"、"主角按下快门后画面定格 1 秒"              |

**要点**：



* 时间轴必须**连续**（避免 "0-3 秒……5-6 秒" 跳段）

* 时间段剧情太少 → 模型自由发挥；太多 → 过度剪切 / 剧情遗漏

* **不要用时间戳控制频率 / 频次**（如 "一秒摇头 3 次"）

* 30 秒内容信息量大，**拆 4–6 个时间段**并写清节奏，否则后半段偏离重点

## 五、Prompt 基础写作

### 1. 参考素材映射（多素材必做）



* 按上传顺序编号（图 1 / 视频 1 / 音频 1），每个素材**文本绑定**，不要只在图片里写映射（如 "主角图上写张三，prompt 里直接喊张三" 容易混角色）

* 多主体用清单罗列："img1-2 是人物 1 对应音频 1；img3-4 是人物 2 对应音频 2"

* 部分参考要写明 "参考哪一部分"："参考视频 1 中施法的动作，视频 2 的环绕式运镜"

* 素材已足够精准时只做**指代**、减少画面复述："严格参考视频 1 的动作与运镜，顺序与视频保持一致"

### 2. 编辑类



* 明确修改范围和内容，配合时间戳，写清 **A→B 过程**

* 例："把视频 1 中 4-6 秒男人喝咖啡的动作改为拖地，其余内容不要变化"

### 3. 首尾帧



* 写在 **Prompt 第一句**："图片 1 为首帧"、"图片 3 为首帧，图片 5 为尾帧"

### 4. 负向控制



* 字幕："不额外加入对白字幕"、"不要字幕"

* 音频分维度单独控制：音效 / BGM / 对白


  * "无 BGM，只生成环境音和动作音"

  * "不要任何声音"

## 六、Prompt 进阶写作

### 镜头 / 动作 / 表情



* 基础内容直接写：景别（大全景 / 全景 / 中景 / 近景 / 特写）、运镜（推 / 拉 / 摇 / 移 / 跟 / 环绕 / 俯冲 / 后拉 / 上摇 / 手持晃动）、机位（低角度 / 俯视 / 第一人称）

* 热门运镜直接写：一镜到底、希区柯克变焦、航拍、FPV、子弹时间、手持、回弹变速

* 小众名词 = **名词 + 描述性解释**："移焦，画面焦点平滑转变，前景树木变模糊，背景人物由模糊变清晰"

* 转场写清**触发点与方式**："第 5s 快速向左横移转场（向左擦除 + 自然叠化）"

* 动作：优先**概括性描述**（"连续做了几组高抬腿和空翻"），只在记忆点动作写细节，不重复写相同动作

* 表情：**描述性语句、少成语**："津津有味" → "脸上带着满足的笑容，大口地吃饭"

### 白模参考 / 线稿分镜



* 白模：写明参考元素（运镜动作 or 光影变化）；叠加参考图时写明对应关系；无参考图时详细描述主体外表

* 线稿分镜：15 个以下分镜；避免过度锐化 / 杂乱 / 多文字的 AI 直出分镜图；prompt 避免前后矛盾；线稿推荐三步：① 指代关系 → ② 整体故事梗概 → ③ 按分镜补齐场景 / 材质 / 运镜 / 动作 / 风格 + 时间戳

## 七、真人感技巧（降低 AI 味）



* 多写真实摄影语言：自然窗光、轻微手持、浅景深、真实皮肤纹理、毛孔、细纹、材质瑕疵、环境杂乱度

* **不要**同时要求：过度美颜、完美对称、超干净棚拍、过强磨皮

* 负向控制："不要 AI 油亮皮肤、不要塑料感、不要蜡像感"

* 小技巧：**保留不完美细节**（细纹、毛孔、轻微不对称、衣物褶皱、真实环境光）—— 真实感来自 "不那么完美"

## 八、省钱抽卡（官方推荐）



* **480p 生成 + 「提升画质」超分**，最高支持超分到 4K

* Web：选择分辨率 480p → 生成后选「提升画质」小工具 → 选目标分辨率

* 对应 CLI：`--draft`（480p 样片）+ `video-super-resolution`（超分）

## 九、九大独家场景（小云雀 Web/App，CLI 未全覆盖）

白模控制（3D 预演）｜片段重拍（只重做不满意段，按片段计费）｜爆款复刻（粘贴抖音链接一键同款）｜营销视频 30s 直出｜超长视频（最长 5min）｜画布（对话式精细编辑）｜创意助手（热点 / 选题 / 方案）｜千人角色库｜480p + 超分

> CLI 可直接用的部分：时间戳分镜、多模态参考、首尾帧（
>
> `--generate-type 1`
>
> ）、编辑 / 延长（
>
> `--task-type edit/extend`
>
> ）、Draft 样片、负向控制（写进 prompt）。片段重拍、爆款复刻、白模 / 3D 导演台主要在 Web 端。
