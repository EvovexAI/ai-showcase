# 文生/图生视频 Prompt 公式（全文）

来源：<https://www.volcengine.com/docs/86081/1805694>（火山引擎·图像生成大模型，智能视频）
> 官方原文摘录整理。最基础、最通用的 prompt 公式，新手先背这套。

## 1. 文生视频 Prompt 公式

```
Prompt =（镜头语言 + 光影）+ 主体（主体描述）+ 主体运动 + 场景（场景描述）+（氛围）+（风格）
```

按需增删元素。**官方示例与结构拆解**：

> 特写镜头，景深，电影胶片拍摄70mm，一个年轻美丽的亚洲女人站在海边，微风吹过她的头发，沙滩，生动的色彩，真实摄影

| 片段 | 对应要素 |
|---|---|
| 特写镜头，景深，电影胶片拍摄70mm | 镜头语言 + 光影 |
| 一个年轻美丽的亚洲女人 | 主体 |
| 站在海边，微风吹过她的头发 | 主体运动 |
| 沙滩 | 场景 |
| 生动的色彩 | 氛围 |
| 真实摄影 | 风格 |

## 2. 图生视频 Prompt 公式

```
Prompt = 主体 + 运动，背景 + 运动
```

- "男人和女人在亲嘴"（主体+运动）
- "天空中下起了大雨"（背景+运动）
- "男人举起了他手里的叉子，天空中下起了大雨"（主体运动+背景运动）

## 3. 首尾帧视频 Prompt 公式

```
Prompt = 主体 + 运动
```

- "鸟在海面上飞"（主体+运动）
- "天空乌云密布，电闪雷鸣"（背景+运动）

## 4. 推荐方式（官方五原则）

| 原则 | 说明 | ✅ 好 | ❌ 差 |
|---|---|---|---|
| **精炼** | 过长提示词主体不突出，通常 512 字符内为宜 | 一顶镶嵌蓝宝石和白金、与高级定制绸缎长裙相映衬的王后冠冕 | 一顶王后冠冕，精致，高雅权威 |
| **具象** | 直白表达画面有什么 | 王后冠冕，一顶镶嵌有蓝宝石和白金的精致冠冕… | 一顶王后冠冕，精致… |
| **主次分明** | 必须有主体描述，仅有动作会偏差 | 一群大学生手里怀抱简历文件夹，人群拥挤，体育场内 | 生成一个火爆投递简历的视频 |
| **可视化** | 描述画面本身，不写音频/音效 | — | — |
| **语言简练** | 简明扼要直击要点，避免古诗/抽象/长难句 | 三只毛绒绒的黄莺在抢占被阳光照耀的树枝 | 几处早莺争暖树 |
| **一致性** | 风格、物种、画面连贯，避免前后矛盾 | 晴天，海滩上人们在享受阳光 | 下雨，雪山，流动的七彩极光，阳光照耀在山上（矛盾场景） |

**细节原则**：Prompt 尽可能详细、好理解（如"一个五彩斑斓的热气球正在上升，背景是蓝色的天空"），主次分明、围绕主要元素运动展开，用自然流畅的语言（"一群毛茸茸的小鸡在编织五彩花环"优于"小鸡，五彩花环，编织，毛绒绒"）。

> 官方备注：视频模型增加物理理解能力后，抽卡时不过度强调原则也可能有不错效果；以上规律仅基于实践提炼，仅供参考。

## 5. 参数调节

- 视频比例：按需求而定（文生/图生/首尾帧）
- 随机种子：默认 -1（随机）；给定正整数可**在同一结果上优化**（对应 CLI `--seed`）
