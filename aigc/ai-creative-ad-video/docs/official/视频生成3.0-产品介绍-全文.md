# 即梦AI 视频生成 3.0 产品介绍（全文）

来源：<https://www.volcengine.com/docs/85621/1792707>（火山引擎·即梦AI，2025.09 更新）
> 官方原文摘录整理。即梦视频 3.0 为 API 能力，Prompt 结构与词典对小云雀 CLI 写作同样适用。

## 1. 接口简介

即梦同源视频生成引擎。准确遵循复杂指令、视觉表达流畅一致、最高 1080P，生成质量与速度兼备。

支持模式：
- **文生视频**：文本提示词 → 视频
- **图生视频 - 首帧**：首帧图 + 提示词 → 视频
- **图生视频 - 首尾帧**：首帧图 + 尾帧图 + 提示词 → 视频
- **图生视频 - 运镜**：首帧图 + 提示词，调节运镜类型与幅度 → 运镜视频

## 2. 能力亮点

1. **指令准确遵循**：复杂指令解析（表情、动作、衣着、多主体交互）
2. **专业级运镜控制**：希区柯克、动感环绕、机械臂等运镜方式，固定参数输入全程精准可控
3. **首尾帧掌控叙事节奏**：仅输入首帧+尾帧即可控制生成内容，实现起止画面自然衔接
4. **画面风格与主体高度统一**：主体 IP 保持稳定、画风统一无跳变
5. **画质分辨率显著提升**：细腻光影与写实细节，最高 1080P

场景案例：电商广告、影视创作、动态壁纸、角色生成。

## 3. Prompt 建议

### 3.1 提示词结构

1. **基础结构**：主体 / 背景 / 镜头 + 动作
2. **多镜头连贯叙事**：镜头1 + 主体 + 动作1 + 镜头2 + 主体 + 动作2 ...
3. **多连续动作**：
   - 时序性：主体1 + 运动1 + 运动2
   - 多主体：主体1 + 运动1 + 主体2 + 运动2 ...

### 3.2 提示词词典

**运镜**（可直接使用的词表）：

| 意图 | 写法 |
|---|---|
| 切换 | "镜头切换" |
| 平移 | "镜头向上/下/左/右移动" |
| 推轨 | "镜头拉近/拉远" |
| 环形跟踪 | "镜头环绕"、"航拍"、"广角"、"镜头360度旋转" |
| 跟随 | "镜头跟随" |
| 固定 | "固定镜头"、"镜头静止不动" |
| 聚焦 | "镜头特写" |
| 手持 | "镜头晃动/抖动"、"手持拍摄"、"动态不稳定" |

**程度副词**：突出主体动作频率与强度，如"快速"、"大幅度"、"高频率"、"剧烈"、"缓缓"
