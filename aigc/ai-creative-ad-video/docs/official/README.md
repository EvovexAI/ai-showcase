## 使用建议



1. **出普通广告片**：Seedance 2.5 手册要点（时间戳分镜 + 素材分工 + 负向控制）→ 套路库选套路 → CLI 出样片

2. **要专业控制**（角色 / 运镜 / 多轨）：3D 导演台 / 画布手册（Web 端）+ CLI canvas 命令

3. **写 prompt 卡壳**：Prompt 指南（即梦 + 通用公式）查模板

4. **控制成本**：积分与参数文档 → 480p 样片 + 超分
