# Prompt 指南要点（即梦AI 提示词原则 + 通用公式）

来源：
- 火山引擎·即梦AI 产品介绍与提示词指南 <https://www.volcengine.com/docs/85621/1834143>
- 视频生成 3.0 产品介绍 <https://www.volcengine.com/docs/85621/1792707>
- 智能视频·文生视频 prompt 公式 <https://www.volcengine.com/docs/86081/1805694>

> 该指南主要来自即梦/OmniHuman 系列（数字人、通用视频），**原则对 Seedance/小云雀同样适用**；模型专属细节以 Seedance 2.5 手册为准。

## 一、文生视频 Prompt 公式（万能骨架）

```
Prompt =（镜头语言 + 光影）+ 主体（主体描述）+ 主体运动 + 场景（场景描述）+（氛围）+（风格）
```

按需增删元素。示例："特写镜头，景深，电影胶片拍摄 70mm，一个年轻美丽的亚洲女人站在海边，微风拂动长发……"

## 二、提示词核心原则

1. **当成讲故事**：用连贯自然的自然语言，**减少孤立词汇堆砌**
2. **只描述动态事件**：图片里已有的静态特征（衣服、首饰）**不用再描述**
3. **清晰、不矛盾、少否定**：用具体而非抽象的描述，分步骤引导
4. **少用否定**：多用正向描述，负向控制单独写（见 Seedance 手册第五节）

## 三、最佳实践模板

```
镜头运动 + 说话角色情绪 + 说话状态（说话/哭泣/唱歌/…） + 具体动作 +（可选）背景事件/其他角色动作
```

示例："镜头从侧面缓慢推进到正面中景。年轻女子坐在窗边，心情平静，轻轻端起咖啡杯，微笑着对镜头说话。旁边的男孩悄悄看着她，时不时转向镜头笑笑。背景中灯光柔和地闪烁。"

## 四、指令类型与编写技巧（官方示例表）

| 想控制 | 技巧 | 示例 |
|---|---|---|
| 连续动作/走位 | 用"先、然后"描述顺序；加入"说话/唱歌"类词 | "镜头跟随，男人转过身看向镜头向前走，陶醉地唱歌。他先用双手摸领口，然后双手张开抬起头" |
| 动作与说话次序 | 说话前后可插入动作编排 | "男人迅速摘下口中的香烟，然后对着镜头开口说话" |
| 多角色 | 着重描述角色间**互动方式**；指定说话人需主体检测（mask） | "画面左侧举着火把的男人先一边看向其他人说话，随后他重新看向镜头" |
| 镜头运动 | 描述**运镜结束时的镜头状态**可精准控制快慢与结束位置；加"迅速"提高运镜响应率 | "镜头向右环绕，聚焦到男人的脸正面" |
| 情绪/微表情 | 结合内容描述细腻情绪变化 | "男人先是神情淡定，随后突然变得紧张惊慌，眉头紧皱" |
| 无中生有/加元素 | 参考图里没有的元素用 prompt 添加 | "父子神情惊愕望向镜头，镜头推进，空气中出现扭曲波动，父子如尘烟被抽入画面深处" |
| 焦点控制 | 前后景不同角色，用提示词控制移焦 | "记者对着镜头报道，身后的国王突然倒地，镜头对焦到倒地的国王" |
| 环境互动 | 让角色与环境自然互动，或描述背景事件 | "猩猩举起右臂保持自拍姿势看着镜头说话，身后火山岩浆逐渐变成蓝色" |

## 五、运镜控制技巧

- **描述运镜结束状态**：如"镜头推进，聚焦到 xx"——比只写"镜头推进"更精准
- **"迅速"等副词**能提高运镜响应率
- 转场写清触发点与方式（同 Seedance 进阶写作）

## 六、注意事项（官方规避方法）

| 问题 | 规避 |
|---|---|
| 结构稳定性 | 15 秒以内较好，15 秒后可能出现衰退 |
| 人脸过小口型不动 | 避免超远景，人脸占比别太小 |
| 人物一致性 | 长时间出镜再入镜易变，避免角色反复出镜 |
| 极端姿势/角度 | 效果可能不佳，尽量常规构图 |
| 随机性 | 单次生成有随机性，复杂场景**多次抽卡** |
| 效果不佳 | 也可以尝试**不输入 prompt**（纯素材驱动） |
| 清晰度 | 视频清晰度高度依赖**输入图清晰度**，尽量上传高清晰图片 |
| 说话表现 | prompt 里写"角色 xxx 说话/唱歌"有助于提高说话表现 |

## 七、提示词结构速记（视频生成 3.0）

- 基础结构：**主体 / 背景 / 镜头 + 动作**
- 多镜头连贯叙事：**镜头1 + 主体 + 动作1 + 镜头2 + 主体 + 动作2 …**
- 多连续动作：
  - 时序性：主体1 + 运动1 + 运动2
  - 多主体：主体1 + 运动1 + 主体2 + 运动2 …

## 八、与 CLI 的落地对应

```powershell
# prompt 直接按上面结构写，喂给 CLI
pippit-tool-cli generate-video --prompt "<按公式组织的镜头语言>" --model Seedance_2.5 --duration 10 --ratio 9:16 --resolution 720p

# 不输入 prompt（纯素材驱动）——CLI 仅支持非空 prompt（除 Draft 转成片），纯素材模式在 Web 端
```
