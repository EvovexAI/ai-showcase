# 积分、模型与参数说明（实测口径 2026-10-15）

## 积分消耗归属

- **谁登录扣谁的**：CLI 消耗的是当前登录凭证（网页授权账号 或 `XYQ_ACCESS_KEY` 账号）的积分，无共享额度。
- 查询：`pippit-tool-cli get-credit-balance` → `{"total_remain_amount":"6396"}`，零余额显式输出 `"0"`。

## 实测成本（Seedance 2.5 · 720p · 9:16 竖屏）

| 项 | 数值 |
|---|---|
| 10 秒成片 | ≈ **200 积分/支** |
| 推算单价 | ≈ 20 积分/秒 |
| 6196 积分可支撑 | ≈ 31 支 10 秒片 ≈ 5 分钟出头的成片内容 |

> 说明：官方无公开单价表，上表按实测单次消耗推算；480p 样片更便宜，1080p 成片/Draft 转成片、超分均另行计费，具体以服务端结算为准。

## 省钱策略（按优先级）

1. **脚本/分镜先定稿**，不拿生成当试错器；
2. **Draft 两阶段**：`Seedance_2.5_draft --draft` 出 480p 样片（便宜）→ 用户确认 → 转 1080p 成片（样片 7 天内有效，两阶段分别计费）；
3. **首尾帧/参考素材一次到位**：`--generate-type 1`、`--image/--video/--audio`，避免"构图不对重来"；
4. **固定 seed** 保证系列一致性，减少重拍；
5. 需要更清晰时再用 `video-super-resolution`（720p → 1080p/2K/4K，另计费）。

## 模型选择

| 模型 key | 定位 | 备注 |
|---|---|---|
| `Seedance_2.5` | 综合最强，默认选择 | 4–30 秒 |
| `Seedance_2.5_draft` | 两阶段样片/成片 | 样片 480p、成片 1080p 固定 |
| `Seedance_2.0_mini` / `_lite` | 便宜、可省略分辨率 | 服务端默认 720p |
| `seedance2.0_vision` / `fast_vision` | 2.0 系列 | 需指定分辨率 |
| `wan3.0` | 写实风格 | 可省略时长/比例/分辨率 |
| `happyhorse-1.1` | 动态/喜剧感 | 可省略时长/比例/分辨率 |

模型以 `pippit-tool-cli model list` 实际返回为准（缓存 5 分钟，`--refresh` 强制刷新）。

## 生视频参数速查

| 参数 | 必填 | 说明 |
|---|---|---|
| `--prompt` | 是（转成片可省） | 用户原始描述，镜头语言最佳 |
| `--model` | 是 | `model list` 的准确 key |
| `--duration` | 按模型 | Seedance 2.5 常规 4–30 秒整数 |
| `--ratio` | 按模型 | `9:16` / `16:9` / `1:1` / `4:3` / `3:4` 等 |
| `--resolution` | 按模型 | `720p` / `1080p`；Draft 两阶段不传 |
| `--image` | 否 | 参考图/首尾帧，可重复 |
| `--video` | 按模式 | 视频编辑/延长需原视频 |
| `--audio` | 否 | BGM/参考音，`.mp3/.wav` |
| `--generate-type` | 否 | `1` = 首尾帧 |
| `--task-type` | 否 | `auto/reference/edit/extend` |
| `--seed` | 否 | 固定种子 |
| `--draft` | 否 | 提交样片 |
| `--draft-task-id` | 否 | 转成片用（样片返回的原始 ID，非 run_id） |
| `--source` | 否 | 宿主统计：豆包办公 `doubao_office` |

## Seedance 2.5 四种模式

| 模式 | CLI 输入 |
|---|---|
| 参考生成 | `--task-type reference` + prompt + 可选图/视频/音频，duration 4–30 |
| 视频编辑 | `--task-type edit` + `--video` 原视频，duration 不传或 `-1`，ratio 不传或 `adaptive` |
| 视频延长 | `--task-type extend` + `--video`，duration 4–30，ratio 不传或 `adaptive` |
| 首尾帧 | `--generate-type 1` + 首帧/尾帧图（顺序），不传 task-type/视频/音频 |

> 不要把 `video_edit`/`video_extend` 配置 key 直接当 `--task-type` 值；`auto` 是下游自动判断值。
