# 长篇网文 · 成章流水线

> 这套流程是《重生1973：我一杆枪，喂饱全屯》（100 章 / 11.1 万正文汉字 / 一卷不漏）跑出来的，  
> 每一步都有脚本，**读数一律来自脚本，不手估**。

## 0. 先立两本册子（缺一不许动笔）

- **创作总纲（唯一权威）**：书名 / 金手指一句话 / 起点 / 爽点一句话 / 体量（几章·每章汉字区间）/  
  人物总册（每人 = **一句话性格 ＋ 一个招牌动作 ＋ 想要什么 ＋ 落章**）/ 情节总表（分卷分单元）/  
  **红线清单** / 写前七问 / 字数纪律。
- **逐章核销表**：人 / 地 / 物 ⊆ 册子；**写前有 ☐ 不落笔**。

## 1. 每章固定结构（顺序不许变）

```
# 《书名》· 第 N 章

> **拍**：①… ②… ③…（本章 3–5 个情节点，写给自己看）

---

## 第 N 章 章名          ← ★章名必须是钩子：动作＋结果／数字／只给一半

正文（对话驱动；开场第一句不许是环境；短拍区一句一段）

---

**（第 N 章 · 完）**

**断在这儿**：…（章末钩子）
```

**★注意**：文件里会有**两行标题**（`# 《书名》· 第 N 章` 与 `## 第 N 章 章名`）——  
**这是给合订本脚本留的去重空间，别删**；合订本脚本会从 `## 第 N 章` 起取正文。

## 2. 三级并段（每章写完必跑，顺序不可换）

短拍（一句一段）是武器，但**中后段不能碎成一句一段**。

```bash
python3 _audit/merge_para5.py <单章.md> 10   # 前 10 段保短拍，其余按意群并
python3 _audit/merge_para6.py <单章.md> 10   # 对白段 ＋ 紧跟的短叙述(≤18汉字) ⇒ 同段
```

- **`merge_para5`**：跳过开场短拍区（默认前 10 段）。**若不加 `10`，开场短拍会被并掉，开篇节奏全毁。**
- **`merge_para6`**：解决 `"他说。"` 被对白隔在外面并不掉的问题（实测均长 26 → 39）。
- **★不为字数来回调**（主编口径）：一次写到位；**超了就让它超，短了就让它短**。一次只跑「并段 ＋ 结构三项」。

## 3. 结构三项 ＋ 红线（一条命令）

```bash
python3 _audit/chk.py <单章.md> ...
# 输出：h1=1 ｜ sep=2 ｜ 汉字=N ｜ 段数 ｜ 对白段% ｜ 标点连写 ｜ 红线
```

- `h1` 必须 = 1；`sep` 必须 = 2（拍后一条、完前一条）；**标点连写必须 = 0**。
- 标点连写正则：`[，。！？；：、](?=[，。！？；：、])` —— **不要把 `。"` 也算进去（假阳性）**。

## 4. 合订本（读稿版）

```bash
python3 _audit/build_hezb.py <out.md> <最大章号> <目录>
```

- 自动按文件名里的 **`第N章`** 排序（不要用 `ls` 字典序：`100-` 会排到 `78-` 前面）。
- 丢「拍」块 / `**（第N章·完）**` / 正文后多余的 `---`；保留章末「断在这儿」。
- **★踩过的坑**：不丢那行重复标题 ⇒ **合订本每章出现两次标题**；不丢正文后的 `---` ⇒ **多出 N 条分隔线**。  
  交稿前必核：`一级标题=1 ／ 章标题数=章数 ／ 独占---=章数+1`。

## 5. 连续性扫描（**每写完一卷或 20 章跑一次**）

一条脚本扫全库，输出「每个有名字的角色：出场章列表 / 首次 / 末次」，并扫红线词。

**三个真实踩过的坑（检查项固定三条）**：

1. **地名·人名前后不一致** —— 前 20 章叫「松岭屯」，我中途写成「红旗沟」，6 处。  
   ⇒ **起新段落前先 `grep` 前文的地名/人名/器物名**。
2. **角色在末尾 20 章消失** —— 张春妮（末 80）、赵小娥（末 80）。  
   ⇒ 规则：**每个有名字的角色 ≥3 次出场、跨 ≥2 卷**；一旦发现"末次出场 < 总章数 − 20"，补一场。
3. **一次性角色** —— 康有德只出场 1 次 ⇒ 补 2 章。
4. **死人未复活**：角色亡故后，其后只能「被追述」（物、话、名字），**不许有行动、不许有台词**。
5. **退场人物不回流**：写明"搬走了"的人，其后不许再在本屯出现。

## 6. 矛盾点与爽点体检（写完一卷跑一次）

```bash
python3 _audit/conflict_audit.py <目录>
```

逐章量四样并出汇总：**对手层（亲/体/行/商/女/外）· 当众度（围观词命中）· 得手（量词）· 章末钩子**。

**★坑**：量词正则必须收**汉字数字**（`[\d一二三四五六七八九十百千万两半]+(斤|元|块|张|桶…)`）——  
只写 `\d+`，全书命中 0，指标全废。同理"当众"别只查"人堆/场院"，要带 `都看着/围过来/门口站/一圈`。

**判据（主编口径）**：

- 当量 ＝ **围观 × 赌注 × 有心 × 回响**，拉满 ≥12；**小打脸须当众**。
- **大高潮每 8–12 章一个**；平路（无对手且无冲突）**≤3 章连续**；**每章至少一个小爽点**。
- 逐章给 S（大高潮）/ A（中）/ B（小）/ C（无对手）四级，再**看空档**：两个 S 之间超过 12 章，就是凹陷。

**实测教训（100 章那份稿）**：总量达标（23 个 S／89 章有对手）**但分布不均** ——  
最长的 S 空档在 **74→88 共 14 章**；卷五 25 章里**没有撑得住的对手**（唯一的新反派一回合就倒）。  
**结论：缺爽不要靠"加数量"，要靠"给那一段立一个"人"**（把某个旧反派升级成卡住全局的中间人）。

## 7. 分量监控（★这一步最容易漏）

**每卷跑一次分量表**（章数 / 正文汉字 / 均章），盯住**趋势**：

- **递减 = 危险信号**。实测：卷一 1402 → 卷二 1112 → 卷三 1188 → 卷四 1045 → **卷五 814**，  
  最后离目标体量差 17%，且收口章被写成"事件化"，冲突当量偏轻。
- **对策（写在每章动笔前）**：**每章先列 3–5 拍**；**拍到 3 拍还不够字数，说明这一章的事不够写，要加一个对手或加一个代价** —— 不许靠形容词凑。

## 8. 交付前最后一遍

- 结构三项 ✓ ｜ 标点连写 0 ✓ ｜ 红线 0 ✓ ｜ 角色核销表 ✓ ｜ 分量表 ✓ ｜ 首尾呼应（第 1 章与第 100 章同一动作/同一句）✓
- 交一份**完本报告**：交付清单 / 读数 / 核销表 / **如实写短板**（薄章清单、离目标字数差多少）。

## 9. 小说 → 120 集集纲（转剧本第一步）

**三件套一起交**：①**人物小传与关系图** ②**大纲＝整个故事的描写** ③**集纲＝每一集的描写**。

**★大纲与集纲是两样东西，别混**：

- **大纲**＝把 N 集的故事**从头到尾讲一遍**（谁、要干什么、谁挡路、怎么破、结果如何、留下什么），按幕分段叙述。**不是**冲突密度表／爆点阶梯表／变现链条表。
- **集纲**＝**一集一段**（≈150–250 字），讲清这一集发生了什么，**末行是该集的收束台词**。  
  **绝不许**写成「钩子／场景／矛盾／起伏／技能点／情绪点／打脸／卡点」的字段清单——那是**执行件的配料表**，不是给人读的。

**★文体纪律（比排版重要）**：凡要给主编通读的件，**去掉内部行话**（锁N／①压②爆／技能点 1.1读痕／大爆B1／L3／E0NN｜浪M），翻成故事语言。  
交付前自问一句：**「主编看得懂吗？」**

**映射法**：小说 100 章 → 120 集 = **五幕各 24 集**（每幕 ← 20 章，1.2 集/章）。

- **大高潮章拆两集**（打熊、一发、山口、站过来、清账……）
- **终章拆三集**（上/中/下）收尾拉满
- 拆完必核：**集号连号无缺无重 ／ 集名无重名 ／ 每集正文 130–280 汉字**（低于 130 的补一句话，脚本见 `scripts/`）
