## ★⑤ 台词四功能核销表：`☐` 是**我的活**，不许丢回给主编（第 41 轮立法）

> **★2026-09-11 段目"判据前移"（第48轮立法）**：段目的（爆科/争吵/立人设/推进）**在细纲阶段就定死**；⑤ 表用 `dlgcheck.py --purpose-src 04细纲.md` **自动带入**，正文阶段**只核不重判**（省掉“逐段重判”的时间）。

**做法（`素材库/dlgjudge41.py`）**：
1. 先按**第 6 指纹**把口号族句数压到母本量级（这才是"该改的"）。
2. 再逐句落判：**脚本关键词只做"预填"**，`功能列`写**我的判定**（①潜台词=嘴上说的≠心里想的／②人设=身份·性格·处境／③推进=触发事件的开关／④情绪=遥控观众），`裁定列`写 `✔已改(正文已替换)` 或 `✔留①②③④`。
3. 段级"本段目的"按**段内主导行为**判：冲突→争吵｜揭底/秘密→爆料｜人物塑造→立人设｜其余→推进。
4. `--changed` 传入"**历批**已改句清单"（用**改前备份 diff** 得出，**每批改完就把新句追加进去**），已改句自动标 `✔已改(正文已替换)`。

6. 收尾：`dlgcheck.py --verify 表.md --src 正文全本.md`（要求 ⛔废句=0、零信号裁定率≥20%、**段目已填（细纲带入）**、表必须覆盖当前正文）。

### ★★改完正文后，核销表怎么"迁移人判"（第51轮 · 41 样板踩出来的坑）

正文改了（合并/删句），345 张表不能重判一遍，要**按内容键迁移**：重建表后，用 **`(集, 角色, 台词)`** 做键，把旧表的人判搬过来；
键对不上的＝真新句，才需要补判。段级按 **`(集, 第几段)`** 迁移（结构没动的集照搬）。

> **★最大的坑（会凭空制造"回归"）**：旧核销表的 **`功能`（marks）列里也藏着人判**——主编把 👤 判完的 ☑ **直接填进了 marks 列**（所以旧表每行至少 1 个 ☑）。
> **只搬"裁定"列、不搬 marks 列**，`≥2 类` 占比会从 **43.7% 掉到 23.3%**——看着像"改完质量掉了"，
> 实际是**我丢了主编的判定数据**。**⇒ 迁移必须 marks + 裁定 两列一起按内容键搬回。**
> 迁移完**先复算一次旧口径**（`marks.count('☑')` 分档）跟旧表对得上，再往下走。

> **★另一个坑**：`dlgcheck.py --verify` 的**表覆盖校验**用的是 **(集, 台词) 多重集**，不含角色——所以
> 只挪动行序（如把 `【本集卡点】` 从末行前挪到末行后）**不会**让表过期；但**改了台词一个字就会**。
> **改了台词 ⇒ 必须重生成表 + 迁移人判，不许改脚本刷数。**

### ★★"整段重写"型改动：**不迁移，直接重判**（2026-09-14 · 51 part3 · 更省事且更稳）

当某一 part 是**全量重写**（不是改几个字）时，按内容键迁移会**大面积键对不上**（等于重判一遍还多花一道工）。
此时直接**重判**，并用**"marks 驱动"的脚本**把人工一致性做到机器级。

**脚本形态（`/tmp/fill3b.py` · 可直接改行复用）**
1. `MARKS = ["☑☑☑☑", "☑☑☑☐", …]` —— **只写 167 条 4 位标记**（序：①潜②设③推④情），与表内句级行**严格同序**；
2. 裁定文本**由 marks 自动生成**：`"留（" + "".join(标签 for 命中项) + "）"`
   ⇒ ★**消灭"手写裁定与 marks 不一致"这一类人误**（第 51 轮踩过：marks 挪对了、裁定忘了改）；
3. 写回时**同步更新三列**：`功能`(marks) / `命中数`(`marks.count('☑')`) / `裁定`；
4. **守卫（必须照抄）**：
   - **段级行优先** —— `if in_seg and ln.count('|') == 5:`；**句级行** `assert ln.count('|') == 8`。
     ⚠ 段级行与句级行前缀同形（`| E21 | 12 |`），**顺序颠倒会把段级行当句级行吃掉**（实测报"句级列数异常 5"）。
   - 末尾双断言：`assert i_sent == len(MARKS)` / `assert i_seg == len(SEGS)`。
5. `SEGS = [(目的, 裁定), …]` 用**列表**（不是表格）传入，段数必须等于表内 ≥5 句的段数。

**判据（每句四选）**：①潜台词＝嘴上说的 ≠ 心里想的（**脚本判不了，只能人判，最重要**）｜
②身份·性格·处境（口癖/职业口吻/结巴/处境暴露）｜③推进＝触发事件的开关（宣战/爆料/拿证据/设条件/钩子/问句）｜
④情绪＝打脸/嚣张/委屈/挑衅/共情/惊叹。
★**别全打 ☑**：全 ☑ 等于没判。51 part3 实测分布＝2 类 64 句／3 类 79 句／4 类 24 句（**≥2 类 100%**，参考线 30%）。

**配套（同一次改动必做，漏一件即假绿）**

- **② 清单的"关键词"按正文实际用词回填**（见 `ruler-calibration.md` §"关键词脱钩"）；

## ★回填脚本的列索引（51 part4 实测踩过的坑 · 照抄别猜）

`dlgcheck.py --out` 生成的核销表，**两级表的列数不同**，用 `line.split('|')` 回填时**极易错位**：

| 表 | 行形态 | `split('|')` 长度 | 关键列下标 |
|---|---|---|---|
| 句级 | `\| E31 \| 1 \| 周念 \| 台词 \| ☐☐☐☐ \| 0 \| ☐留 ☐改 \|` | **10**（首尾各一个空串） | 功能=**5**、命中数=**6**、裁定=**7**；台词=4、角色=3 |
| 段级 | `\| E31 \| 13 \| ☐爆料… \| ☐留 ☐删 \|` | **6** | 目的=**3**、裁定=**4**（**段内句数=2，千万别覆盖**） |

**51 part4 实战翻车**：段级行误按"目的=2、裁定=3"写入 ⇒ **覆盖掉了"段内句数"列**，
`--verify` 立刻报 `❌ 段级表解析不到任何行（列数被改）` ⇒ **段级判据整项失效**（假绿形态⑩的变体）。
**守卫写法**：
```python
if in_seg and ln.startswith('| E') and ln.count('|') == 5:   # 段级优先
    p = ln.split('|'); assert len(p) == 6; p[3] = dest; p[4] = jud
elif re.match(r'^\| E\d+ \| \d+ \|', ln) and ln.count('|') == 8:  # 句级
    p = ln.split('|'); assert len(p) == 10; p[5] = marks; p[6] = k; p[7] = judge
```
**另**：回填前先 `cp` 一份 `/tmp/bak-*.md`；回填后**必跑**
`dlgcheck.py --verify <表> --src <正文>`（`--src` 是"表与正文一致性"的唯一校验，
正文改过而表没重生成时它会直接报 `核销表已过期`）。
