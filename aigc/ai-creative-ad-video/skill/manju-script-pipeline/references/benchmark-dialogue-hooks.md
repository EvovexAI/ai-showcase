# 表演层定标：**台词硬度** 与 **钩子六型**（标杆机器拆解法）

> **什么时候用**：主编说「**你看看这个台词 和钩子**」／甩来同类爆款让你"参照"／**故事骨架已定但要给"每一句怎么写、每一集怎么收"定标**／
> 剧本被批"**台词平**""**不像人话**""**集尾没劲**""**都是过渡集**"。
> **核心纪律**：**给"表演层"定标不能靠印象，必须取同类标杆做机器统计。**
> 印象会说「台词挺好」；读数会说「**长句占比 0.7%，标杆 17%**」。

---

## 一、口径（先说清，否则数字不可比）

- **汉字数**＝`len(re.findall(r"[\u4e00-\u9fff]", s))`，**不计标点**，**不计场景行/人物行**。
- ⚠️ **与门禁 `content_chars()` 不是同一把尺**（门禁把标点也算）⇒ **跨文本比较只在本口径内成立**，报告里必须标注。
- **集尾末行**＝**集内最后一行内容行**（若体例把 `**【本集卡点】**` 放集尾，则取**卡点行之前那一行**）。
- **对白句**＝形如 `角色（语气）：台词` / `**角色**（动作）："台词"` 的行，取冒号后正文并剥引号。

## 二、抽取与切集（可直接复用）

```python
import re, zipfile
def docx_text(p):                       # docx → 纯文本（不装 python-docx）
    xml = zipfile.ZipFile(p).read("word/document.xml").decode("utf-8","ignore")
    xml = re.sub(r"<w:tab[^>]*/>", "\t", xml); xml = re.sub(r"<w:br[^>]*/>", "\n", xml)
    out=[]
    for pa in re.findall(r"<w:p[ >].*?</w:p>|<w:p/>", xml, flags=re.S):
        t="".join(re.findall(r"<w:t[^>]*>(.*?)</w:t>", pa, flags=re.S))
        out.append(t.replace("&amp;","&").replace("&lt;","<").replace("&gt;",">").replace("&quot;",'"').replace("&apos;","'"))
    return "\n".join(out)

# 切集：阿拉伯数字序数
re.fullmatch(r"第(\d+)集", line.strip())
# 切集：汉字序数（不少剧用「第一集」）——★必须两种都试！
re.fullmatch(r"第([一二三四五六七八九十百零\d]+)集", line.strip())
```
**★坑**：**单集行没有"–"时，正则 `^\| (\d+)[–-](\d+) \|` 会漏** ⇒ 写成 `^\| (\d+)(?:[–-](\d+))? \|`。

## 三、必采的 9 个指标（缺一个都读不出病）

| # | 指标（每集均值） | 为什么必须采 |
|---|---|---|
| 1 | 内容汉字 | 对齐字数线 |
| 2 | △ 行数 / △ 汉字 | ★**判断"是不是 △ 写多了"** |
| 3 | 对白条数 | 台词密度 |
| 4 | **对白汉字** | ★与 2 配对 |
| 5 | **对白字占比** | ★★**≥45% 才算台词驱动；30% 上下＝"△ 说明文"** |
| 6 | **对白句均长 / 中位数** | ★★平不平 |
| 7 | **≥24 字占比；≥36 字条数** | ★★★**长句配额——这是"台词没硬度"的量化根因** |
| 8 | 场景数分布 | 对齐"场景≤3" |
| 9 | **集尾末行类型（对白 : △）＋末行汉字** | ★★决定钩子配比 |

## 四、两条已实测的基线（可直接当对标尺）

| 指标 | 《暖房》120 集 | 《荒岭1985》16 集 |
|---|---|---|
| 单集内容汉字 | 542（中位 510，343–972） | 555（313–938） |
| △ 行 / △ 汉字 | 29.2 / 228 | 9.3 / 261 |
| 对白条数 / 对白汉字 | 23.9 / 315 | 12.5 / 293 |
| **对白字占比** | **58.0%** | **52.9%** |
| **对白句均长 / 中位** | **13.2 / 9** | ≈23（含括注） |
| **≥24 字占比** | **17.0%**（2866 句） | — |
| ≥36 字条数 | 203 | — |
| 场景数 | **3 场占 94/120（78%）** | 1–3 场 |
| **集尾类型** | **对白 74 : △ 46（61.7%）** | **对白 10 : △ 6（62.5%）** |
| 集尾末行汉字 | 均 10.1 / **中位 9** | — |

**⇒ 三条可直接引用的结论**：
1. **对白字占比 < 40% ＝ 病灶**（治法＝**补台词，不是删 △**；△ 往往一点不少）。
2. **`≥24 字` 占比 < 5% ＝ 长句断档**（治法见 §六）。
3. **集尾"对白 : △ ≈ 6 : 4"**——**"集尾必台词"是按 60% 拟的，会整类砍掉"动作悬停"钩**。

## 五、钩子：六型 ＋ 配比 ＋ 撞拍

| 型 | 定义 | 例 |
|---|---|---|
| **A 半句悬停** | 尾句语义未完成（**靠语义，不靠破折号**；实测仅 2 集真用"—"） | 「再晚——／咱可能连上山的路都赶不上了」 |
| **B 反派定策** | 末拍切反派，**说出下一刀** | 「明着拿不了——那就换个法子」「明晚。上山。」 |
| **C 危险扑脸** | 危险具象化、**已贴到脸上** | 「都别管了！跑！！！」／狼群血盆大口一拥而上 |
| **D 目标宣告** | 主角当场说**下一步干什么** | 「该去找真正能烧一整个冬天的东西了」 |
| **E 揭示/摊牌** | 末拍**掀底牌** | 「因为这些事，我已经经历过一次。」 |
| **F 动作悬停（△ 尾）** | 末行是动作/结果，**停在半空** | 「第二辆卡车的帆布帘。轻轻动了一下。」 |
| — **收束型** | **大结局不设钩**，改首尾回扣道具 | — |

**配比（120 集参考）**：`F 40 ｜ A 24 ｜ C 22 ｜ B 18 ｜ D 10 ｜ E 6`。
**三条禁令**：①**禁连续两集同型**；②**同一单元的 3 个爆杀锚点不许同型**；③**每 10 集覆盖 ≥4 型**。
**△ 尾只准两种**：**(i) 危险扑脸**、**(ii) 结果刚落地**（打脸刚发生、众人反应）；**禁总结/抒情**。

**★撞拍续演**（两部都在用）：**上一集末拍 ＝ 下一集开场镜头**。
`E45 末「帆布帘轻轻动了一下」→ E46 首「帆布轻轻晃动」`；`「给我……劈叉！」→「给我……劈叉！！！！！ 」`。
**允许原句重演，但必须加码**（音量/语速/感叹号/动作升级）——**不加码＝重复**。

## 六、台词：四式 ＋ 长句纪律

**讲理式打脸四式**（当代/年代题材通用）：
① **即时威胁**（「再碰我娘一下，我把你爪子掰折」）
② **荒诞类比**（「怀的是孩子，又不是尚方宝剑。咋的，揣个娃，全林场都得给你磕一个？」）
③ **算账反问**（「那六十张煤票留着过年贴窗花啊？」／「你算盘珠子都快崩我眼睛里了」）
④ **反向立誓**（「你跪雪地里磕得脑瓜子冒火星子，这房我都不要」）
＋ **素材化打脸**：把打脸**换算成可清点的东西**（房→车＋60 张煤票＋200 元现金）。

**三连定量打脸（最强拍）**：`动作 × 数字 × 追问` —— `五百！` `五百！` `一共一千，还要不要？`
⇒ 与 `锁12 打脸四节拍`（**判词 ≤12 字 ＋ 必带一个数 ＋ 不给台阶**）**逐条同构**。

**★长句纪律（关键纠偏）**：
- **"≤24 字"是分布指标，不是硬上限**：标杆 ≤24 字占 83%，**24–45 字占 17%**。
- **长句 ＝ 同一情绪的同向递进**（分句三四个，**全在骂同一件事**）；
  **≠ 复合任务句**（一句塞四件不同的事、因果断裂）——**后者才是病**。**可以长，但必须一件事、一个方向。**
- **动作打断台词**（比"说完再打"狠）：`（抬手一巴掌打断）`；`工人甲：……你俩折腾一宿也是白——` ＋ `△"轰隆隆——！"`。
- **群演合唱＝群众判词**（"头一回见这样式要彩礼的，这老娘们也太虎了，寒碜不寒碜呐！"）⇒ 把 `表九 态度轨迹` **写成"当众开口的话"**，别写成内心变化表。
- **喜剧缓冲**：虐点刚过立刻给一个笑点（「我不是认错，刚扭到腿了」），防情绪一路下坠。
- **土话用法**：`啥/咋/整/犊子/膈应/寒碜/攒劲/没牙磕/瞎嘞嘞`——**把一句损话换成一个画面**（"酱块子""脚盖子""老家雀穿棉袄"），**不是堆脏话、不直写脏字**。

## 七、可借／不可借（合规与主编指令优先）

- ❌ **熊／虎／豹等珍稀动物打斗**（备案红线：避免"捕杀珍稀动物"）
- ❌ **灵宠系统／面板／兽王之心／空间**（"不要搞那么多的秘密"）
- ❌ **一箭钉入兽眼**类血腥写实（改"套/夹/困"为主、正面搏杀为辅 ⇒ 也正好落实"升级三步不许跳步"）
- ❌ **重生先知**（前世只作技能来路，不做谜、不做先知）
- ✅ 四式台词／素材化打脸／三连定量打脸／群演合唱／动作打断／喜剧缓冲／六型钩子与 6:4 配比／撞拍续演／集尾短句（中位 9 字）
