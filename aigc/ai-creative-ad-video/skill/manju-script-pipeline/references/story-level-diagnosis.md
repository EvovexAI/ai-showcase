# 「整体有问题」型反馈的处置法：故事级体检 → 缺口核算 → 换版判断

> 触发场景：主编说 **「你这个故事。整体有问题！」「这个故事不行」「感觉不对」「重新想想」**
> —— 即：**不是挑某一句台词、某一集的问题，而是对整个故事骨架的否定**。
> **2026-09-17 立法**（52《女猎户》主编"整体有问题"→ 换版 v2），跨项目永久有效。
>
> **★最容易犯的错**：①一被说"整体有问题"就慌了乱改；②或者只回一句"您指的是哪儿？"（把活推回给主编）。
> **正确做法**：**不动笔 → 自己体检 → 自己列病灶并附文件依据 → 给方案 → 等拍板。**

---

## 第一步 · 收到"整体有问题"时的三步（禁止抢着改）

1. **停手**。不写一个字，不改一个文件。（对应"指令边界"铁律：一次指令只做一件事。）
2. **做故事级体检** —— 读这几件就够：`01 构思`（母题/logline/三线）／`04 大纲`（幕结构/矛盾/爆点阶梯）／`04c 大纲+小传`／`05 细纲`前 30 集。**找的是骨架病，不是错别字。**
3. **回复格式 = 诊断 + 依据 + 方案 + 待确认**：
   - 每条病灶必须**指到具体文件**（例："`04 §一` 自述『她赢一半的集 0 个』"）；
   - **给出 2–3 个修法方向**（甲：不动骨架／乙：换赛道／丙：换外壳），并**明确推荐一个**；
   - 最后才问一句让他拍板。**别只问不判。**

---

## 第二步 · ★四条高频"整体病"自查清单

| # | 病灶 | 怎么查（可观测） | 典型证据长什么样 |
|---|---|---|---|
| a | **主角全程碾压** | 数一下"她目标未达成的集"占多少 | 剧情文档里写着「"她赢一半"的集 **0 个**／"她受着"的集 **0 个**」 |
| b | **反派不狠 / 前段无靶子** | 列出反派名单，标每个的**首次登场集**与**危害** | 反派全是"他不是坏，他只是老/怕/小贪"；大反派第 65 集才登场 |
| c | **标签不干活** | 把题材标签（穿越/重生/系统/金手指）拿去正文里搜**功能**，不搜词 | 贴着"穿越狩猎"，而穿越只承担 3 行开场，之后一字不提 |
| d | **欲望太抽象** | 把主角的欲望念出来，问"这一集能量出来吗" | "把名字写进《猎户册》""想被认可"＝行政手续级欲望 |

**★b/d 专项判据**：
- **靶子判据**：**前 20 集里，观众能不能指着一个具体的人说"我恨他"？** 不能 ⇒ 病灶 b。
- **欲望判据**：对比主编给过的范例（末世剧"让家人活下来"）——**具体、切身、每集可验证**。抽象的社会性欲望（要名分、要被认可、要改规矩）**撑不起长剧**，只能当副线。

## 第三步 · ★★治"拖沓"：要"换顺序 ＋ 加钩子"，**不要"删挫败"**

**实测反例（52 血的教训）**：
- 主编先说"拖沓、不够爽" ⇒ 我按"**删尽一切她受着的集** ＋ 爆点前置（第一个大爆由 E20→E1）"改版；
- 结果：**门禁全绿**、`04` 里"她赢一半 0 个／她受着 0 个"；
- 主编随后判：**「你这个故事。整体有问题！」**

**⇒ 因为"删掉受着"的同时也把张力删掉了。** 主角一路赢 96 集 = 没有起伏只有爬坡 = 疲劳。

**两条硬规**：
1. **主角在前 1/3 必须有一次"拼尽全力还是没保住"的真代价**（死了人／丢了地／家人受伤）。
2. **每 20 集至少一处"世界强、她弱"的压迫段**（天灾／群敌／制度性封锁）。
3. 治拖沓的正解：**换顺序（爆点前置）＋ 加钩子（每集结尾拉满）＋ 压铺垫（无过渡集）**；**不是删挫败**。

## 第四步 · ★主编给定新骨架时的权责边界（框架 vs 中观）

**框架层（一个字不许改）**：主线走向／关键事件与因果／人物关系与结局／题材调性。
　→ **做法**：主编的消息**逐字照录**另存一件（文件名带「主编给定·原文照录」），开头写清
　　「依 `铁律0` 第 5 条『主编框架 > 母本 > 我自造』，本文**一字未改**」。
**中观层（我可填，填完报过目）**：分几浪/几单元／矛盾点排布／**集数分配**／爽点·情绪点分布／卡点。
　→ **框架里带的"量化要求"就属于这一层**，必须**由我铺满，且铺满再动笔**（核销前置）。

### 4.1 量化要求 → 折算表（先算总账）

| 要求 | 折算 |
|---|---|
| 每 3 集一大爽点 | 总集数 ÷ 3 |
| 每 2 集一小打脸 | 总集数 ÷ 2 |
| 每 N 集一爆杀 | 总集数 ÷ N（**除不尽时按"单元内固定锚点"取整**，如 20 集单元取 E7/E14/末集＝每单元 3 发） |

**★除不尽怎么办**：**不要用绝对网格**（30 集后必漂），改用「**单元内固定锚**」——
如"单元 20 集 ⇒ 第 7 集、第 14 集、单元末集"。**骨架的【单元高潮】通常就落在第 3 个锚点上，可用来对表。**

### 4.2 骨架切组 → 逐组列表 → 铺点位 → 列缺口（四步）

1. **把骨架切成"事件组"**（主编原文的分组，通常 3–4 集一组），**逐组列表**：单元｜组｜集号区间｜组宽｜事件摘要｜有无明标爽点/钩子。
2. **机器复核分组**：**总集数必须等于全剧集数、零缺口、零重叠**、组宽分布、平均组宽。
　（脚本：正则 `^- \*\*(\d+)(?:-(\d+))? 集` 抓区间，逐集打点看有无漏/重。）
3. **铺点位网格**：爽点落组末（4 集组给 1.5 个）；打脸按组配额（3–4 集组 2 次）；爆杀落固定锚点。
　**★不要为了对齐去动主编的分组** —— 爆杀落点与"组末爽点"错开，节奏反而更活。
4. **★列缺口清单（最有价值的一步）**：逐个爆杀/爽点落点去骨架里找对应事件，
　**找不到配得上强度的事件的，逐条指名"第 X 集、在哪一组、要补什么"。**
　（52 实测：18 个爆杀落点里 **12 个**骨架没给够强度的事件 —— 这就是我要报给主编的活。）

## 第四步之补 · 骨架拿到了，还常缺这四样（★2026-09-17 主编四条裁定）

主编"整体有问题"之后往往会给一份新骨架。**骨架＝事件层，它通常缺下面四样** ——
**补这四样是"中观层填装"的活，填完报主编过目。**

### 补一 · ★动力锚（最高优先级）

> 主编原话：「**第一集写穿越过来是个寡妇，她是没有动力的！**如果穿越过来，**有几个可怜的弟弟妹妹**！」

**★判据**：**主角对"自己"负责 ＝ 没动力；主角身后有一个"在等死的人" ＝ 动力自己就有了。**
- 「寡妇」只对自己负责 ⇒ "改嫁"只是**是非问题**，不构成**必须立刻动手的压力**；
- 「身后有几个饿到奄奄一息的弟妹」⇒ **她今天就得上山**，一集铺垫都不用。

**动力锚三件套（开局三集内交代完）**：
1. **要养的人在等死**（不是"我要变强"）；
2. **一个具体死线**（断粮／寒冬将至／逼婚／税款／原主被打死）——抽象欲望（要名分、要被认可）撑不起长剧；
3. **一句锚定台词**，每 10 集复现一次。范例：**「我在，他们就饿不着。」**（对标《荒年通现代》"空手回去娘和小黎得饿死"）

### 补二 · ★"会升级"要变成"可见进度条"

> 主编原话：「主角**会升级，会有逻辑**」

**三层阶梯**（逐单元兑，做进骨架表里）：

| 层 | 例 |
|---|---|
| ① **猎物／对象**（打怪） | 野鸡野兔 → 狍子/獾 → 野猪 → 狼 → 害兽群 → 大型兽 |
| ② **装备／技能** | 柴刀绳套 → 铁夹踩套 → 套阵 → 弓弩 → 猎枪 → **猎犬队** → 阵型协作 |
| ③ **家底／地位**（致富） | 断粮 → 有肉 → 余粮现钱 → 大钱 → 盖房 → 承包/带队 |

**★逻辑三硬规（防"凭空会"）**：
1. **技能有来路**（前世身份／师承）；
2. **装备有来路**（打到的猎物换钱买的，**不能凭空出现**）；
3. **升级三步不许跳步**＝**先侦察（读痕）→ 先布套（不硬碰）→ 再正面**。

**★验收**：每一级都要有**当集可见的变化**（换了什么工具、打到了什么、家里多了什么）。

### 补三 · ★当代题材的"合规底盘"（联网必查项）

**官方备案提示原文**（DataEye 榜单单页）：
> 「狩猎/雪林类…**避免"非法狩猎""捕杀珍稀动物"等敏感情节**。可将"狩猎"设定为"在特定区域内的**生存技能训练**"或"**与自然和谐共处**的求生故事"。」

**⇒ 三条硬约束**：
1. **对象不得是保护动物**（当代打虎豹熊＝违法；改写成"害兽成群"）；
2. **把"合规"前置成身份设定**（承包山场／护林协防／害兽防控／持证）——**先定"她有权做什么"，再写她做了什么**；
3. **用行业规矩承载"和谐共处"**（不赶尽杀绝／幼兽不打／山财不可独享），**兼作打脸素材**（别人乱来）。

**★通用化**：任何会踩线的职业/行为（打猎、采药、挖矿、行医、赌、酿），**先给主角一个合法身份与边界**。

### 补四 · ★"这类小说怎么写"的调研法（主编：「你联网看看这类的小说」）

**五步**：
1. **查赛道数据** —— DataEye／剧查查的漫剧百强榜、红果热度榜；判"爆发期"还是"过气"。
   （52 实测：2026-08 抖音AI剧漫剧百强榜，**赶山赶海/山猎 4 部上榜、合计约 23.89 亿播放**；单日爆款《雪林猎徒》**1.6 亿**；行业判语＝"**狩猎赛道已完成用户教育，进入爆发期**"。）
2. **扫同类 10 部以上** —— 每部标：体量／数据／**核心结构一句话**。
3. **抽"标配骨架"** —— 动力锚·死线·升级体系·**打脸节奏（多为"报仇不隔夜"＝当集或下集就还）**·家底进度条·**"分家断亲"这类标配大爽点**。
4. **找差异位** —— 同类全是男频？我方用女频 ＝ **微创新**，正踩行业总结的爆款公式第 3 条（"**针对成熟母题做微创新**，不挑战受众审美惯性"）。
5. **查合规红线** —— 榜单单页常有"备案实务提示"，**最省事的避坑口**。

**★铁规**：调研结论**必须能翻成骨架里的一个具体改动**，**不许只做读书笔记**。

## 第五步 · ★换版 ≠ 改版（判据 ＋ 处置）

**判据**：改名/改年代/改亲属关系后，**先跑一遍"旧版标识扫描"**——

```python
for w in ["旧女主名","旧男主名","旧年代词","旧地名"]:
    print(w, new_skeleton.count(w))
```
**若全为 0 ⇒ 这是换版，不是改版。**

**处置**：
1. **v1 整体封存**：先 `tar -czf` 打快照，再移入 `_archive_v1_<特征>/`。
2. **v2 从 `00 写法声明` 起重走**，**绝不在 v1 文件上打补丁** —— 否则同一目录两套口径，门禁与正文互相污染。
3. **出一张"全库连锁改动清单"**：逐件标 `改 / 重写 / 重做 / 重算 / 作废封存`。
　52 实测要动的：`00` 改 · `01/04/04c/05–08/05b` 重写 · **`02` 重灾（世界观锁＋年代锚点表整块作废）** · **`03` 重灾（20 人位→12）** · `03b/03c/09/10/11/12/13/门禁参数` 重算 · **正文＋docx 作废封存**。**19 项。**
4. **给七步改造路线**（封存 → `00` → `01` → `02` → `03` → `04` → `05` 细纲 → `6′建尺子` → 正文 → 门禁），**等主编点头再动**。

## 附二 · ★"换版重走"的施工协议（2026-09-17 52 实测定型）

**换版决定后的动作顺序（不要跳步）**：

1. **起跑快照（改前必做）**：`tar -czf /tmp/x.tgz -C <项目目录> .` **再 `mv`** 进去。
   ★**坑**：直写进被归档目录会报 `Can't add archive to itself`（归档仍在生成，静默少收文件）⇒ **必须先打 `/tmp`**。**校验＝`tar -tzf … | wc -l` 报条目数**。
2. **v1 原件一律不打补丁**：v3 全部**新建件**（文件名带 `v3`／`-2026-09-17`），v1 原地保留 → **有朝一日整体 tar 后移入 `_archive_v1_<版名>/`（要主编点头）**。
3. **`00` 重做＝阶段 0 的唯一产物**，必含七块：①写法声明（＋"相对线失效"硬后果）②**版本史三代对照与处置**（附**换版判据读数**：旧标识 count=0）③立项卡（世界观／动力锚／不设清单／合规底盘）④单元结构＋量化折算＋**锚点写死**⑤上线逻辑（赛道数据）⑥**风险对策逐条挂病因**⑦成功标准（**含表演层指标**）＋**文件地图逐件标"v3 现行 / 待重做"**。
4. **哪些不能自己定**：人物命名、地名、合规底盘、骨架补装——**只列"待主编定"表，不动手**；上游件里已出现的地名可引用，但**必须注明"如主编另定以主编为准"**。
5. **自证**：新件字节数 ＋ v1 原件 **md5/mtime 未变** ＋ 快照条目数。
6. **下游顺序**：`01` → **`02`（锁是"立法本"，把新锁一次性并入，别零散打补丁）** → `02b` → `03`/`03c`/`03b` → `04` → `05–08` → `09` → `11 建尺子` → 正文。
   ★**不要在旧 `05–08` 上补新指标**（那是 v1 件）——**重做时一次性带上**。

## 附三 · ★"年代／设定口径被主编纠正"的施工协议（2026-09-17 52 实测定型）

### 触发
主编一句话改设定口径，例：**「也是可以用枪的，有持枪证，定位是 70 年代！」**（此前 `02` 通篇按"当代山村"写）。

### 根因（★比"漏项"更贵）
**假前提 > 漏项**。漏项能补；**我把主编没说的设定（年代／地名／职业）自行补齐，并当成既定事实写进了下游 5 个件 + 2 个文件名** ⇒ 主编一句话，**要回头改 7 个位置**。
> **★预防铁规**：**凡主编没明说、由我补的设定，必须在 `00` 立项卡里标 `★我补 · 待主编确认`**，不得当既定事实往上下游传播。
> **判据**：回看"上游件原文"——`04d`（主编骨架**原文照录**）**通篇真的没写年代** ⇒ 说明"当代"是**我加的**，不是主编给的。

### 施工六步（**不许只改主件**）

**① 先定位"口径"落在哪几类位置** —— 用 `grep -rl "<旧口径词>" .` 全目录扫，**四类必须分别处理**：

| 类 | 例（52） | 处理 |
|---|---|---|
| **A. 活件正文** | `02`／`00`／`04e`／`16` | **改**（逐处串行 `Edit`，禁整文件重写） |
| **B. 文件名** | `…（当代山村·十七把锁）…` | **`mv` 改名**（不是删）；改完**回填文件地图里的自引用** |
| **C. 下游引用／抬头** | 各件首行 `> 选题 52 ｜ … 当代山村 …` | **改** |

**③ ★"禁用词"必须扫两遍——一遍找词，一遍找语境**
> 禁令清单一升级（如"一九八〇年代以后器物"），**旧清单本身也会命中新词**（合同／承包／老板／打工／村委会／乡镇政府／三轮车…）。
> **判据**：每个命中都要问 **"这句是不是在'禁用语境'里"**（禁用清单／`锁4b` 禁用右栏／提醒句）。**否则会把"禁令本身"误判成违规。**

**④ 时代词库要成对写**：不只写"×× 年代**没有**什么"，还要写"**有**什么"（52 新增：洋火／煤油灯马灯手电筒／工分粮票布票工业券／大队·生产队·公社／供销社·代购代销点／介绍信·报备·开条子／赤脚医生·大队卫生室／持枪证）。
**★每换一个年代，必须配一条"政治红线"**（52 立：绝对不写政治运动／批斗／派系／成分／口号语录／真实政治人物；台词与 △ 不出现"革命／路线／斗争／阶级"；**冲突只用"生计与人情"**；**写错一条＝整集作废**，与备案合规并列为一票否决线）。
