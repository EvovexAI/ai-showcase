# 流程硬规矩（L0-L4 唯一检查顺序 · 三跑制 · 母本自检三查 · 段目前移 · 判据唯一化）

> 本文是 `SKILL.md` 的延伸阅读。**流程怎么走、按什么顺序查、一件事归哪把尺子**，全在这里。

### ★★★三跑制（改正文后只跑一次门禁 · 第48轮立法 · 治"每次修改这么久"）
> **病根（诚实说）**：把门禁当"**探照灯**"用了——每跑一次就照出"下游已过期"，回头改、再跑，形成循环。
> 门禁是"**验钞机**"，**只在最后一次验**；根因**不是工作量，是顺序错**。

**顺序（不可乱）**：① 改正文（**一次改透**，中途不跑门禁）→ ② **一次性同步下游 6 项** → ③ **只跑一次门禁**（`run_gates.py` 一键）→ ④ 交付。

**下游同步 6 项（改完正文必勾）**：
| # | 下游产物 | 同步动作 |
|---|---|---|
| 1 | **字数** | 重算逐集字数（去空白；不含集标题/完标记） |
| 2 | **故事点核销关键词** | **按正文实际用词回填**（改词就改关键词，**不许改正文迁就脚本**） |
| 3 | **台词四功能核销表⑤** | 重生成 `dlgcheck.py <正文> --out 表.md --purpose-src 04细纲.md` ＋ 重填人判 |
| 4 | **part 重切** | 某集行数/边界变了就重切正文分 part |
| 5 | **docx** | 重跑 `md2docx.py`（**只转正文**） |
| 6 | **报告** | 更新 07/10/14 等报告里的数字 |

> **口诀：改一次，勾六项，跑一次。** 只有"交付前那一次门禁"算数；中途自检可以，但**不许拿中途结果当"不过"的判据回炉**。

### ★★新判据/改过的尺子，上线前必过"母本自检三查"（第48轮立法）
① **算得出数**——母本侧**集数/句数 ≠ 0**（读得进、切得出集）；
② **两侧同口径**——同一解析器＋同一参数＋**同一登记口径**（人名一律**简称**、对白一律**去标点**）；
③ **与母本自身事实不矛盾**——已知优秀的母本自己过一遍**不该报红**（母本报红＝尺子错，不是母本错）。
**三查全过**，才把母本侧读数写回 `门禁参数.md` 当基线；**绝不使用"没配母本的绝对阈值"**。

### ★★★段目的"判据前移"（第48轮立法）—— 段目的在细纲定，正文只核
段目的（爆科/争吵/立人设/推进）**在阶段5 细纲就定死**；生表时 `dlgcheck.py --purpose-src 04细纲.md` **自动带入**，正文阶段**只核不重判**。
细纲段目的表格式（脚本自动识别）：`| 集 | 段 | 目的 |`（「段」＝该集内 **≥5句长对话段**序号，从 1 起；目的可多选如 `争吵/推进`）。

### ★★★唯一检查顺序 L0-L4（第49轮立法 · 治"同一个东西反复验证"）

> **主编原话**：「**仿写是先分析母本，然后我们开始写，写完再去检查问题，检查问题是有顺序的，按照顺序来**，但是你有环节出了问题。」
> **我出的三个环节故障**：① **把门禁插进"写"里**（门禁当探照灯）→ 反复验证；② **顺序倒置**（机器门禁＝字数/格式排第一 → 为凑字数删内容 → 把上游弄坏 → 回头重验上游）；③ **同一件事两把尺子**（改一遍要验两遍）。

**★顺序即纪律：从"最贵的"查到"最便宜的"（上游→下游、贵→便宜）**

| 层 | 查什么 | 唯一出口 | 红灯归属 |
|---|---|---|---|
| **L0 校尺子**（不查剧本） | 母本自检三查 | 见上一节 | 修尺子 |
| **L1 内容**（最贵） | **在不在｜说得通吗**：①故事点保留 **100%**（②）②**台词因果链·信息源（Z40＋S3a）**③命名/称谓（N1） | ② / `dlgchain.py` / `namecheck.py` | **回细纲** |
| **L2 结构** | **够不够｜够不够密**：情节分量（③）／场景密度（N2-d）／Z17-Z19 排布 | ③ / N2-d | 回大纲细纲 |
| **L3 语言** | **干不干净｜像不像人话**：**L54→L54b→L54c→L54e**／**L57**／L45·L53·L55·L59·L60·L39·L48／**⑤含 Z41** | `langcheck.py` / ⑤ | 回正文 |
| **L4 格式与配额**（最便宜） | **齐不齐｜超没超**：排版两行标注·N2-c／**字数**·△≥8·对白≥14·首句对白·集尾钩·卡点（①） | ① / `namecheck.py` | 回正文（**只删整句/整段，不许压扁句子**） |

**三条纪律**：
1. **读完 L1 再动 L2；L1 有红，绝不动 L3/L4**——否则又是"改下游、坏上游"。
2. **写的时候不跑全量门禁**：写作期只允许**离线轻量自检**（不进总表、不下判定）；全量门禁**只在阶段 8 跑一次**。
3. **`run_gates` 内部行序按工具效率保留**，但**读与改一律按 L1→L4**。

### ★★★引"经典台词"的红线（第54轮立法 · 素材库《台词军火库》配套）

> **病**：为了给台词"上炮"，去抄经典影视的金句——**照抄＝抄袭，观众一眼认出"这不是这部剧说的话"**。

**两类语料，待遇完全不同**：

**民间语料的三门槛（不是"能直用"就随便用）**：
① **年代**——农耕/乡土歇后语用在**农村年代剧正好**，放都市职场剧＝穿越；
② **地域**——带西北/南方色彩的（「瓜贩子捂瓜瓤」「沙窝里栽杨树」）**跨区要换**；
③ **人物**——**★歇后语是"有闲心的人才说的话"**：一个愁着揭不开锅的人不会说俏皮话。**谁在什么时候有闲心，比说什么更重要。**

**进正文的三条纪律**：① **一集最多 1 句**（歇后语是味精，撒三句人物变"顺口溜机器"）；② **不整句念，说半句留半句**（「上坟烧报纸——（顿）糊弄鬼呢」，老农民不背完整歇后语）；③ **重口句（"老母猪敲门"式）只给反派/泼妇立人设，不给主角**。

**★引用必须逐条上网核实出处**——**不凭记忆引**（记忆里的"名句"常是串台/讹传）。

## ★大纲阶段的三条自证（2026-09-12 · 选题49《那年夏天山丹红》实证）

新母本 43 集、**逐集一一对应**时，大纲落盘后**必须先跑一遍脚本自证**，再交主编。三条：

### 1）集块数／母本映射 一一对应（**用脚本数，不用眼睛数**）
```python
import re
t = open('03-大纲NN集-剧名.md', encoding='utf-8').read()
blocks = re.split(r'^### E(\d+) ', t, flags=re.M)          # 集块按 `### E编号 ` 切
for i in range(1, len(blocks), 2):
    no, body = int(blocks[i]), blocks[i+1]
    m = re.search(r'←母本\s*E(\d+)', body.split('\n')[0])   # 每集标题必须带 ←母本 EN
    assert m and int(m.group(1)) == no, f'E{no} 母本映射错位'
```
**实证产出**：43 集块 ✓｜**母本集号 43/43 无错位** ✓。**★换皮项目最怕"集号悄悄漂移"（母本 43 集被我方写成 42 或 44），只有脚本能第一时间发现。**

### 2）★★"骨架表 ＋ 卡点末行定稿表"双表制
**问题**：大纲的逐集骨架里，末行常常是**画面**（`△他转身走了`），而门禁要的是**末行留台词指下集炸点**。若只写骨架，到了正文才发现 18 集末行不是台词 ⇒ 又要回上游。
**治法**：
- §6 逐集骨架 = **骨架**（允许末行为画面）；
- **§7 另立"43 集卡点末行汇编"独立表，全部写成台词**，并**明文声明"§6 与本表冲突时以本表为准"**；
- 脚本自检 `卡点（末行台词）` 在**每一集块内**存在（实证：首版 **E43 结局集漏标** ⇒ 补上后 43/43 齐）。
**★结局集也要标卡点**（末句＝留个念想，如"五年以后我们再回来看"），**不许因为"全剧终"就免检**。

### 3）角色外形／名字去重（**同一外形不得给两个角色**）
**实证**：首版把 **E33 门外的赵桂兰** 与 **E35/E36 的老何家老太太** 都写成"穿灰布褂子的老太太" ⇒ 观众分不清，且两个"婆婆"的戏会串。

**★同类风险**：母本里两个"王姐/陈嫂"式的重名配角，换皮时要**合并或改名**（我方把"班主任＋作文赵老师"合并成 **吴老师**一人）。

**一句话口诀**：**大纲落盘先自证——集块数对、母本映射不错位、卡点表另立且集集齐、老人外形互斥。**

## ★细纲（`05-细纲NN集`）落盘自证尺子（2026-09-12 · 选题49 定型 · **可直接复用**）

细纲是"准动笔"件，动笔前必须证明它**没有结构性缺项**。判据＝**集块／场景两行同伴／卡点／三条硬线／集号／映射**六项。

**★踩过的坑（必读）**：初版判据写成 `re.findall(r'^`场景：', body, re.M)`——**要求行首就是反引号**；
但细纲真实行格式是 **`- `场景：…`／`出场人物：…``（行首是 `- `，且两行标注同处一行）**
⇒ **命中 0 行**，而脚本只报"不匹配集: []"，**`0 == 0` 真空通过并照打 ✓**（铁律㊽）。
另外 `^`出场人物：`` 更是**恒为 0**（它不在行首）。**教训：计数类检查必须打印"命中总数"，并把 0 当红灯。**

```python
import re, sys
from pathlib import Path
t = Path('05-细纲NN集-剧名.md').read_text(encoding='utf-8')
segs = re.split(r'^### E(\d+) ', t, flags=re.M)          # 集块按 `### E编号 ` 切
rows=[]; fan=0
for i in range(1, len(segs), 2):
    no=int(segs[i]); body=segs[i+1]
    # ★判据＝「行首 `- ` 前缀」（不得用 ^` 锚定；出场人物与场景同行，用"行内包含"）
    sc = [l for l in body.split('\n') if l.startswith('- `场景：')]
    s, p = len(sc), sum(1 for l in sc if '`出场人物：' in l)
    rows.append((no, s, p,
                 '卡点末行' in body,
                 len(re.findall(r'△ ≥\*\*(\d+)\*\*', body)),
                 len(re.findall(r'对白 ≥\*\*(\d+)\*\*', body)),
                 re.search(r'字 ≤\*\*(\d+)\*\*', body).group(1) if re.search(r'字 ≤\*\*(\d+)\*\*', body) else '?'))
    fan += s
bad=[]
if len(rows)!=43: bad.append(f'集块数={len(rows)}')
if fan==0:        bad.append('场景命中 0 行 ⇒ 尺子失效（假绿㊽）')
print('集块数:', len(rows), '｜场景场次合计:', fan, '（=0 即尺子坏了）')
```

## ★★★多册蓝图「合订本」的生成 ＋ 三步校验（2026-09-17 · 选题52 实证 · **可复用**）

**触发**：主编说「**整理下 大纲 人物小传 和细纲 在一起，不用word。我看看有没有问题**」。
—— 要的是**给人通读的一本**，不是加工件。**抬头必须写死「本件只用来看，不是工作件；改动回源文件改，本件由源文件重新生成」。**

### 一、生成：用脚本重组，**不要 `cat` 拼接**
四步（选题52 的 `build_heben.py` 可照抄）：
1. **`cut_head()`**：切掉各册的 `# 标题` ＋ `> 抬头块`（到第一个 `---` 为止），**去重抬头**；
2. **`demote(+1)`**：各册二级标题降为三级，**给"部分"级标题让位**，防止与合订本自己的 `# 第N部分` 撞级；
3. **★幕标题跨册去重**（最容易漏的一步）：**同名幕会横跨两册**（如「幕二 E21–40」在 `05` 尾写一次、`06` 头又写一次）。
   处置＝**第二次出现降为 `#### 幕X（续 · 实际集段）`**，**集段必须用 `re.findall(r'^\*\*(E\d{3})\*\*')` 从区间内实际算出**，不许照抄标题里的范围；
4. **自证下沉**：各册 `## 本册自证` 切出来，统一挪到 `# 附录一`；
   再加 **`# 附录二 · ★已知问题与待裁定`**（把验证件 `09 §八/§九` 整段搬过来）——
   **主编就是来找问题的，把"你要点头的 N 条"放进同一本，比让他翻第二个文件强**。

**卷首必备**：`## 目录`（表：部分／内容／源件）＋ `## 使用说明`（体例几行／硬线／场景号白名单／**集行怎么读**／**"重点看三件事"**）。

### 二、★三步校验（缺一步就可能把假象交出去）
| # | 查什么 | 怎么查 | 陷阱 |
|---|---|---|---|
| 1 | **结构** | 幕标题数（`### 幕` ＋ `#### 幕（续）`）／一级标题数／集行数 | —— |
| 2 | **★零丢失** | **逐行多重集比对**：源四册（去抬头去自证）的每一行 vs 合订本「第三部分」区间的每一行，`Counter` 比计数，**只允许"被重写的 2 条幕标题"对不上** | **禁用"字数差"当判据** —— 末集段落会吃进下一册册头、幕标题被重写 ⇒ **字数差是假象**（实测 -78/+126/-117/-229，实际零丢失） |
| 3 | **逐集体例** | **按"集行位置区间"切分**（`re.finditer(r'^\*\*(E\d{3})\*\*')` 取相邻位置做端点），逐集数八行 | ① **末集必须截断到 `# 附录` 之前**，否则 E120 的区间一路吃到附录，**报出"技能点×2／打脸×2"的假红**；② 切分终点遇到 `## 本册自证` 也要截断 |

### 三、★★编号混排陷阱（本轮真踩，且**已写进交付件**才发现）
**同一批数字里混着三种编号**：`打脸第 N 次`（**序号**）｜`E0NN`（**集号**）｜`幕N`（**幕号**）。
**实证**：`09` 里把「**★打脸（第 19 次）**」误当集号，写成 **"E19（20 字）"** —— 真值是 **E28**。
清单一并错：分布写 `15×3`，实测 `15×2`（**列表加起来是 10 处，却声称 9 处，自己就不自洽**）。
⇒ **硬规矩**：**凡"序号／集号／幕号"三者同现的清单，复算时必须把"集行"打印出来当锚**（`awk` 打出区间内 `^\*\*E\d{3}\*\*` 做定位），**不许凭记忆映射**。

### 四、★另一个假绿：判词长度是"行内数字"，不是"引号内容"
判词字数在细纲里写成 `**判词 20 字＋带数（…）**`。
**用"找引号里的台词再数字数"的正则去测 ⇒ 一处都测不到 ⇒ 假绿"超 12 字 = 0 处"**（真值 9 处）。
⇒ 口径固定为 **`re.finditer(r'判词\s*(\d+)\s*字')`**；**报告里贴出去的每一项读数，都要能对着"它自己的写法"复现**。

## ★★★改"多件"之前的备份：整目录打包快照（2026-09-17 · 选题52 实证 · **一次教训换来**）

**病根**：改正文时习惯只备份正文；**改蓝图（02/03/03b/04/05/09/11/清单）时，8 件一个都没备份**（且项目**无 git**）⇒ 回退只能靠"改动处带标记 `★YYYY-MM-DD 第N次调整`"全库定位，**不是逐字节回滚**。

**治法（写死）**：**凡一次动 ≥2 个文件，先整目录打包快照**（不是只备份主件）：

```bash
# ① 目标包必须建在 /tmp，再 mv 进项目目录
tar -czf /tmp/snap_<项目>.tar.gz -C "<项目绝对路径>" .
mv /tmp/snap_<项目>.tar.gz "<项目绝对路径>/改前快照-<日期>-<事由>-全目录.tar.gz"
# ② ★效果达成必须拿可观测读数证明（"动作做了 ≠ 生效"）
ls -la "<项目>/改前快照-…tar.gz"                     # 体积非 0
tar -tzf "<项目>/改前快照-…tar.gz" | wc -l            # 条目数 ≳ 项目文件数
tar -xzOf "<项目>/改前快照-…tar.gz" ./<任一源件> | grep -c "<该源件独有的一串>"  # 抽查可真解出
```

**★坑（本轮真踩）**：`tar -czf <目标> -C <同一目录> .` ⇒ 目标文件**落在被归档的目录里** ⇒
`tar: Can't add archive to itself`，**仍会产出一个包，但包不完整**（＝最坏的一种失败：看起来成功）。
⇒ **先建在 `/tmp`，再 `mv`**。

**配套**：被改的**生成物**（清单表、合订本、门禁总表）也要各自留 `.bak_<日期>_<事由>`，
因为它们是"人判回填"的成果，**不是纯机器可再生的**（重跑只会给你脚本预标，人判会丢）。

## ★★对白技巧：想让"反用打脸"落地，写成"一问一答"，不要写成"两句同形句并列"（2026-09-17 · 选题52 E1 实证）

**病相**：为了让女主"拿对方的话打回去"，最容易写成两句**同形句紧挨着**：
```
赵氏：进了周家的门，就是周家的人。
柳雁：我进周家门，是周家求的。
```
**两个问题**：① **观众会听混**（竖屏一闪而过，两句都带"周家…的人/的"）；② **`run_gates` L54c 会抓**——实测报 **"同句式复读 疑似 1 对 · 相似 0.77"**。

**正解（比硬扛更好）**：**把前一句改成"逼问"**，让反用变成"她拿对方的话作答"：
```
赵氏：你算周家的什么人？
柳雁：我进周家门，是周家求的。
```
**收益三样**：① 反用更利（问题抛出来，答案砸回去）；② 字面撞车消除（L54c → ✓）；③ **还更短**（本轮少 6 字）。

**★泛化**：**"反用"靠的是"语义回旋"，不是"字面复刻"**。凡发现"两句长得像，但一句是另一句的回旋镖"，
**优先改前一句的形状（改成问句／改成否定句／换个动词）**，别去动女主那句（她那句是判词，不能动）。

## ★★★"蓝图有 · 正文无"型缺口的诊断法 —— 三问逐集核销（2026-09-17 · 主编四问打回后立）

**病征**：门禁全绿（②故事点 100%），主编却问「**这里面女主的动力是什么？是什么推动剧情走向的？反派的目的是什么？你这些都写了么？**」

**病根**：**八道门禁没有一道管"动机"和"引擎"。**
②故事点表的列头是 `#｜骨架故事点｜骨架集｜功能｜正文落点｜落点集｜核销关键词｜保留` ——
**`功能` 列填「钩子／压／爆／立人设／伏笔」，是情绪功能，不是动机功能**；②核的是**事件**（"她撕了文书"），不核**动机**（"她为什么撕"）。
⇒ **② 能 100% 全绿，而母题／动力线／引擎／反派目的可以整体空着**（＝"②全绿≠没问题"的又一个活例子）。

**三问逐集核销（建议立为第 ⑩ 道门禁）**：

| 核什么 | 取数来源 | 怎么判 |
|---|---|---|
| ① 她这一集**要什么**（正向目标） | `01构思方案 §四` 本幕目标 ＋ `05细纲` 本集钩子 | 正文必须有一句她说出来／做出来的**正向目标**；**只有"我不干"＝不通过** |
| ② 谁挡着、他**为什么**挡（反派目的） | `03人物设定` 小传·**想要** | 本集在场反派必须有一处露目的（可一句台词）；**不露＝黄灯** |
| ③ 这一集结束她**得到了什么**（C 线推进） | `01构思方案 §三` 的 **B咬C** | 必须落一件**可变现的东西**（粮／皮／钱／契／猎点）；**连续 2 集没落＝红灯** |

**配套基线**：把 `01构思方案 §一/§二/§四` 的**母题、logline、六幕目标**抄进 `09写前验证` 的 C1–C12，
变成"写前必摊开的**第五张表**"——**否则 `01` 永远只是一份"写给人看的方案"，不进任何门禁。**

**两种典型形态（实测）**：
1. **"动力线方向反了"**——女主收尾句把动力锚在**回击反派**上（如"也不给周家出一分力"），
   而母题指向的是**本事／山**（"这山认本事，不认男女"）。
   ⇒ **收尾宣言必须指向"她要拿到什么"，不许指向"她要气死谁"。**
2. **"引擎只滚一格"**——三线咬合设计里 **C 线（变现）连续断档** ⇒ 10 集打了 7 次脸、家底一分没涨
   ⇒ 场面热闹、没有积累、120 集的进度感没有发动机。
   ⇒ **每一次打脸成功必须立刻换一样可变现物落地（哪怕一句"换了半袋盐"）。**

**台词侧同族病：★"复合任务句"** —— 一句台词塞 ≥3 件事（称呼＋道德绑架＋交易＋期限）。
**根因常是"为了交代清楚，把一个角色写成了讲解员"：一个人不可能同时是凶手和说明书。**
⇒ 治法：**把"交代设定"拆给第三人（旁观者讲背景天经地义），把"目的"塞回当事人嘴里**；
再配一句**"为什么"**（他这么干图什么），因果链才接得上。
**判据**：`锁14 (2)` 只念台词四问 —— 陌生人能答出「谁／在哪／干什么／**对面是谁、他图什么**」。

## ★★★铁律66（人物目的链）落地清单 —— 「没输入 ≠ 没病」（2026-09-17 立 · P0）

## 多册蓝图合订本（`build_heben` 家族 · 2026-09-17 补 · 本轮踩坑后固化）

**用途**：把多册蓝图（大纲 `04` ＋ 人物 `03/03c` ＋ 细纲 `05/06/07/08`）合成**"给人通读的一本"**。
**定位**：**只读件，不是工作件** —— 改动一律回源件改，本件由生成器重生成。

### 四步生成
1. `cut_head()` 切掉各册 `# 标题`＋`> 抬头块`（到**第一个 `---`** 为止）
2. `demote(+1)` 各册二级标题降三级（给合订本自己的 `# 第N部分` 让级）
3. **幕标题跨册去重**（同名幕横跨两册 ⇒ 第二次降为 `#### 幕X（续 · E0lo-E0hi）· 标题 ｜ 季节`；**集段必须从区间内实际 `**E0NN**` 行算出，不照抄标题**）
4. **自证下沉**：各细纲册的 `## 本册自证` 切出 → `# 附录一`；`09` 的 §八/§九 → `# 附录二`

### 三步校验（脚本内置）
① 结构（一级标题数／幕标题数／集行数）
② **零丢失**：非标题/非分隔行的**逐行多重集比对**（**禁用"字数差"**）
③ 逐集体例：按**集行位置区间**切分，逐集数八行

### ★★★坑一：往 `## 本册自证` **之后**加任何带 `---` 的内容 ⇒ **自证正文整块消失**
- **根因**：`split_self()` 把 `## 本册自证` **及其后全部**切为 `sec`，随后又对该 sec 跑 `cut_head(sec)`（＝"切到第一个 `---` 之后"）
  ⇒ **`---` 之前的自证正文被 `cut_head` 反向吃掉**。
- **★正确做法**：**任何附加块（段目的表／备注／附录）一律放 `## 本册自证` 之前。**
- **自检读数**：`自证块内 '---' 个数 == 0`。
- **实证（52《女猎户》2026-09-17）**：把《附 · 段目的表》加在 `05` 的 `## 本册自证` 之后 ⇒ 合订本附录一里 05 那一册只剩表格，
  `集数：E1–30`／`★起伏点`／`★铁律核销`／`技能点` **全部消失**；移到自证之前后**全部回归**。

### ★★★坑二：三步校验会**假绿** —— "零丢失 0 处" 与 "自证整块消失" **可以同时成立**
- **为什么**：校验②只比对**主体行**的多重集；**自证下沉后的行不在比对源里**。
- **判据**：改完合订本**必须另跑一条"关键行回归"**——逐个搜
  `集数：E…`／`★起伏点`／`★铁律核销`／`技能点`／`下一册` **在附录一里都在**。
  ⇒ **报"0 处缺失"先证伪"是不是我的比对范围漏了那一坨"**。
- **同族口诀**：`跳过≠全绿`｜`未校准≠全绿`｜`cp 了≠能回滚`｜**校验脚本自己也会假绿/假红**。

### ★坑三：这类生成器常写成**无 argparse**（硬编码 `OUT`）
⇒ 用法是**在项目目录直接跑**，输出与校验一次打印；**别试 `--help`**（会 `IndexError`）。

### ★坑四：行数对不上先别慌 —— 先排除"自证下沉"造成的**错位显示**
`diff 旧合订本 新合订本` 会把"下沉到附录一的行"显示成"删除＋添加"，看起来像丢失。
**以三步校验②＋关键行回归为准**；净行数变化应≈"本轮源件净增行数"。
