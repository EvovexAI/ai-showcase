# 「给主编通读」的可读化交付件：故事大纲 / 人物小传 / 单集细纲

> 触发场景：主编说 **「给我看看大纲」「集纲呢」「细纲按这个模板填」「整理成 Word」**，
> 或者你发现自己交出去的东西**主编读不懂**。
> **2026-09-17 主编两次纠错后立法**（52《女猎户》），跨项目永久有效。
>
> **★一句话总纲**：**蓝图有"两副面孔"** —— 给我自己用的是**执行件**（要素表／量化表／字段清单），
> 给主编看的是**故事**（叙述文）。**同一部剧，两套件并存，绝不混用。**

---

## 一、★★ 定义（主编原话纠错 · P0）

> 「你知道什么是大纲，什么是细纲么？你写的不对！**大纲是对整个 120 集故事的描写，集纲说每一集的描写**！你写的啥？**我都看不懂你讲的啥！**」

| 件 | 是**什么** | 字数/形态 | 不是**什么** |
|---|---|---|---|
| **故事大纲** | **整个故事的描写** —— 把这 N 集从头到尾**讲一遍**：谁、他要干什么、谁挡路、怎么破、结果如何、留下什么 | **一段到底的连续叙述**（可自然分段，**禁小标题／禁分幕／禁"他要的是…"这类结构句**） | ❌ 冲突密度口径 ❌ 大矛盾表 ❌ 爆点阶梯 ❌ 变现链 ❌ 技能铺排 ❌ 情绪点基准 |
| **集纲（＝细纲）** | **每一集的描写** —— 一集一段，讲清这一集里发生了什么 | 约 **150–250 字**／集，含集尾那句台词 | ❌ 每集的「钩子／场景／矛盾／起伏／技能点／情绪点／打脸／卡点」**字段清单**（那是配料表） |
| **人物小传** | **姓名单独一行 ＋ 一段散文** | 约 **150–250 字**／人 | ❌ 七项分段模板（来路／外形／他信什么…）—— 那是写作执行件 |

**★故事大纲的推进链（固定）**：
`前情/前世 → 重生或开局后的第一个动作 → 关键转折 → 逐步壮大 → 对抗势力 → 最终成就 → 结尾回扣／新钩子`

**★人物小传的段内顺序（固定）**：
`身份定位 → 来路/前史 → 性格 → 与主角的关系与作用 → 成长弧线与结局`
　排序：**主角第一**，其后核心伙伴／家人／反派／次要角色。

## 二、★★ 文体纪律：清"我的行话"，**留"主编的词"**

**凡是要"给主编通读"的交付物，必须去掉内部工作行话。**

| 类别 | 例子 | 处置 |
|---|---|---|
| **主编自己模板里的块名／字段名** | `【本集结尾终极钩子】`／「固定人设**锁条**」／「女主／前期核心反派」这类**定位词** | **✅ 原样保留** —— 这是主编给的语言，顺手洗干净反而错 |
| **我自己内部那套** | `锁12`／`E0NN` 集号简写（该写「第 1 集」）／`伏笔`（该写「引子」）／`卡点`／`起伏`／`情绪点`／`技能点`／`打脸`／`大爆·小爆`／`变现`／`铁律N`／`浪N`／`①②③`／`§`／`△`／`判词`／`首帧`／`①压②爆` | **❌ 必须清掉**，翻译成故事语言 |

**★判据一句话**：先问「**这个词是谁定义的语言？**」—— 主编给的留，我自己造的清。
**★交付前自问**：「主编打开这个，能不能顺着读下去？」—— 不能，就是**文体错了**，不是排版错了。

## 三、单集细纲「模板体」（主编 2026-09-17 给的通用模板 · 女猎专属）

### 3.1 五条死守规则

1. **每集固定结构**：`前置冲突 → 中段反转/发力 → 结尾爆钩子`
2. **每集只讲一件主线事**，不杂线
3. **女主人设统一**（见 3.3 锁条）
4. **单集场景 ≤3 个**
5. **每集结尾四选一钩子**：危机升级／对手加码／更大猎物出现／身份风险

### 3.2 单集块结构（照抄块名，顺序不许换）

```
## 第 N 集 · 标题
【本集核心任务】      ← 一句话：这一集她要办成/挡住什么
【本集爽点】          ← 1–2 个，要具体到"当众做到了什么"
【本集铺垫信息】      ← 开场前观众必须知道的
【场景1｜开篇3秒强冲突】  地点｜时间  ／ 剧情
【场景2｜中段女主发力】    剧情推进 ／ 关键动作
【场景3｜收尾＋本集高潮】  结果
【本集结尾终极钩子】      ← 四选一
```

### 3.3 文件头部两块（放最前，防写崩）

- **`〇、本剧人物锁条`**：女主 5 条（话少动作快不解释／狩猎主导男主只辅助不救场／对家人温柔对外人警惕／不恋战不滥杀守山规但抢口粮硬刚／从不委屈自己）＋ 主要角色各 1 条 ＋ **`★每集必须做到`** ＋ **`★禁用（避雷清单）`**。
- **`一、单元总览（第 A–B 集）`**：`开篇(1–2)困境铺垫＋首次破局｜中段(3–6)连续收益＋持续被针对｜高潮(7–9)最大危机爆发｜收尾(第10集)彻底翻盘＋埋下个单元引子` ＋ **升级链** ＋ **收益链**。

### 3.4 单元大篇章模板（**10 集一单元**，批量做剧不重复、层层升级）

| 段 | 集 | 干什么 |
|---|---|---|
| 开篇 | 1–2 | 困境铺垫 ＋ 首次破局 |
| 中段 | 3–6 | 连续收益 ＋ 持续被针对 |
| 高潮 | 7–9 | 最大危机爆发 |
| 收尾 | 10 | 彻底翻盘 ＋ 埋下个单元引子 |

### 3.5 避雷清单（AI 烂剧五条）

❌ 女主突然心软原谅极品　❌ 女主遇事等男人来救　❌ 大段心理独白、书面台词
❌ 每集都是"抢肉吵架"一个循环　❌ 年代穿帮、冒出现在的词

## 四、交付前机器自检（**"保护性动作"必须配可观测读数**）

```python
# 1) 逐集字段完整性 + 场景数
blocks = re.split(r'^## ', t, flags=re.M)[1:]
FIELDS = ["【本集核心任务】","【本集爽点】","【本集铺垫信息】",
          "【场景1｜开篇3秒强冲突】","【场景2｜中段女主发力】",
          "【场景3｜收尾＋本集高潮】","【本集结尾终极钩子】"]
for b in blocks:
    assert not [f for f in FIELDS if f not in b], "字段缺"
    assert len(re.findall(r'【场景\d', b)) <= 3, "场景超 3"

# 2) 行话逐词 count —— ★必须人工复核每个命中项
for w in ["锁12","E0","卡点","起伏","情绪点","技能点","打脸","大爆","变现","伏笔","铁律","△","§"]:
    c = t.count(w)
    if c: print(w, c)
```

> **★两条假阳性陷阱（52 实测）**：
> 1. `锁` 会命中主编模板的「人物**锁条**」；`钩子` 会命中字段名 `【本集结尾终极钩子】` —— **都是要留的**，不是问题。
> 2. 因此**只报"命中 N 处"就交出去 ＝ 把判断责任推给主编**。自检要交的是「**命中了哪些 ＋ 为什么它是/不是问题**」。
