# 门禁与脚本详解（run_gates 唯一入口 · 复用脚本清单 · 假绿陷阱 · 自证红灯）

## 复用脚本
- `scripts/check_generic.py (file.md)`：机器门禁。解析 `## 第N集`/`第N集` 分集，报告每集 字/△/对白/首句对白/集尾钩/字数达标，汇总自说自话句数，全绿打印 `★机器门禁全绿★`。判定：`fail_*==0 and zsh_sent==0`。
- **`素材库/menjin.py`**（跨项目通用的“独立门禁”·**不在 `run_gates.py` 的调用链里**，用于单跑或新项目体检）：`menjin.py <正文.md> [--eps N] [--relax "17,28,42,50,57,60"] [--addr "规则;..."] [--red "词1,词2"] [--maxdial 24]`。
  核：**红线词**（内置 `灭口/冥婚/迷奸/下药/強奸/诈尸/配阴婚/害死/棺材里爬/活人配灵牌`；`杀` 单列待人工）／**政治红线 A+B 类**／真实地名／**集数连续性**／**逐集字数（含 8-A 白名单）**／**每集恰 1 行卡点**／**称呼锚点**（子串级）／**超长对白**。
  **★参数名**：`--eps`（**别名 `--episodes`**，两者等价）／`--relax`（8-A 白名单）／`--maxdial`（默认 30；**本工作流口径＝24**）。
  **★拿它判一个项目必须带参数**，否则默认 40 集 ⇒ 集数/字数/白名单三类**全假红**：
  ```bash
  $P 素材库/menjin.py 正文全本-E1-E60.md --eps 60 --relax "17,28,42,50,57,60" --maxdial 24
  ```
  **★`--addr` 是子串级、且只支持两段 `[集数条件]:禁用词`**：它只会说“这些集里正文有没有这个词”，**无法区分“谁对谁说的”**。所以“顾长河第几集起叫她阿云”“女主第几集改口叫娘”这类**称呼锚点不能用 `--addr`**（会制造假红），须**人判**（写进 `03 人物小传` 称呼表 ＋ 终审逐条核）。
  **★红线词不随参数变**：`menjin` 报的红线词命中，**一律按真红处理**（别把它并进“参数假红”——《绣娘不低头》上一轮就这么错了一次，本轮才纠回来）。
  **★“超长对白”口径（第 72 次尺子校准 · 2026-09-12）**：旧版按**整行台词串**计长 ⇒ 与 ① 机器门禁的“**按 `。！？…` 切句取最长**”口径不同＝**恒假红**（本剧 `--maxdial 24` 下旧版报 12 处、① 报 0 处）；且旧正则**强求括号动作** ⇒ `**角色**：“…”` 无动作行被静默丢弃。**已修为“最长句”口径 ＋ 括号动作可选**。
- **`素材库/namecheck.py (file.md)`**（跨项目通用，2026-09-10 新建；**第43轮升硬＋双格式**；**第44轮 N2-b 精度修正＋新增 N2-d**）：**主编点名过的三类病**的门禁——①命名一致（**一家人姓氏一致**／**一人一名**／**一名一人**）②集间＋场景层（**N2-a-A 跨集整句复读＝❌硬红**〔母本基线 2、仿写须 0〕／**N2-a-B 换场无过渡＝⚠提示**〔短剧主流手法，不判红〕／**N2-b 场景不动＝⚠提示**〔连续≥3集、**该集场景名去重后唯一**且同名；母本基线 1〕／**N2-c 说话人未在该场「人物行」＝⚠提示**／**N2-d 场景密度＝❌硬红**〔**集均场景数 ≥ 母本×0.7**〕）③人物记忆自洽（**盲人视觉越界**／已故者共同行动／年龄时间锚点）。
  参数：`--family "张家=李" --names "新支教老师=新支教" --blind "周婆婆" --dead "春芽娘" --mother <母本>`。
  **★ `--mother` 是本门禁的灵魂**：给了它，N2-a-B／N2-b／N2-c／N2-d 会自动打印**母本同尺子基线**（防"拍脑袋阈值"）。**`run_gates.py` 已自动透传 `--mother`**（④b 行），并把**提示项与 N2-d 倍率显形到总表**。
  **★ 双格式适配**：同时认仿写格式（`## 第N集`／`场景：`／`出场人物：`／`**角色**（说明）："对白"`）与母本格式（`第N集`／`N-N 地点 时 内`／`1-1：地点 时 内`／只有场景标记无集头／`人物：`／`名字：对白`）——**没有这个，尺子量不了母本，一切"与母本比"都是空话**。
- `素材库/langcheck.py (file.md)`：语言层（L39 无效描写配额／L45 语系／L48 爽点密度／L53 伦理称谓／**L54 跨集重复／L54b 集内重复（指纹①）／L54c 同句式换词复读（指纹④·同集内）／L54d 跨集口头禅（指纹⑤·对白开场段·与母本折算比）／L54e 跨集同拍换词复演（指纹③的跨集版·跨集两两相似度·母本非0⇒只提示）**／L55 已故者／L57 电报句／L59 生僻字／L60 前后半落差／Z28 比喻）。
  **注意**：①其 L60 判据已改**相对口径**；②**它解析不了中文数字集号的母本**（比母本前先确认集数不为 0）；③**L48 必须传参才有意义**：
  `langcheck.py <md> --dead "春芽娘" --villains "刘翠花,翠花,刘铁蛋,铁蛋,赵桂芳,桂芳" --sweet "1.47,0.20,41"`
  —— `--villains` 给对立方名（**含简称**，否则 △行里的"翠花"漏计），`--sweet` 给**母本同尺子实测**的「吃瘪集均,旁观集均,母本有反应集数」（**第 3 个数不给，就只报数不判分布**）。
  **★2026-09-10 已固化**：不传 `--villains` 时它会在结论段打印 `⚠ 未校准项（结果不可用于判定）`，`run_gates.py` 据此**拒绝打全绿**（exit 2）——"假绿"这条路已堵死。
  **★L54b/L54c/L54d 是新增的三道真门禁**（此前"集内同句写两遍""同句式换词复读""跨集口头禅"**没有任何脚本查**）：L54b 精确匹配报**集内重复**；L54c 用 `SequenceMatcher` **同集内两两比相似度**（**≥0.8 红灯**、0.6–0.8 疑似，**疑似必须全列、不许 `[:12]` 截断**）；**L54d 取"对白开场那一段"比母本同口径（称呼归一化＋按对白量折算），报"自造口头禅"**。
  **★L54d 的红灯能力已自证**：注入 10 处「好娃」→ 报 `好娃×13` 红灯、exit 2；净本绿。**改判据后必须重做注入自证**（本门禁连校准 4 次，前 2 版一次假红一次假绿）。
  **★L54c「疑似」不清零的判据**（第42轮）：**先拿母本跑同一版脚本**——母本自身 18 对（含 2 对硬红）、仿写 0 硬红＋17 疑似＝1.06×母本 → **不清零**，只改"同集内·同角色·同拍做两遍"的 5 对。
  **★★L54 的"代理"必须是被比对的**那一行**，不是整行**（第 43 轮·第 30 次尺子校准）：L54/L54b 原先拿**整行**（`**角色**（提示）："台词"`）当去重键 ⇒ **同一句台词只要提示词不同（`（转头）` vs `（一句）`）就逃检**。43 实证：脚本报"L54 零跨集完全重复 ✓"，但 E15↔E49「那都是多少年前的老黄历了呀」**一字不差**（只差括号提示词）。**改法**：`dlg_line_owner` 键改**台词文本**（`d.strip()`）、`act_line_owner` 键改**△文本**（`s[1:].strip()`）。**代理选错比阈值错更致命**——这是"假绿形态⑨判据的代理选错"的原型。
  **★L54e 跨集同拍换词复演**（第 43 轮·第 31 次尺子校准·新立）：L54 只管**整句完全相同**、L54b/L54c 只管**同集内** ⇒ **跨集·换词·近重复**是三家共同的盲区（"同一场戏换个词再演一遍"）。判据：对白/△ **长度≥8**，**只比跨集、同类型**（对白↔对白、△↔△），`SequenceMatcher` **≥0.8** 记一对；整句完全相同的跳过（L54 已管）。
  **★L54e 母本自检（必须先做，否则不能升硬）**：同一版脚本跑母本 → **阈值 0.80 时母本 3 处／仿写 0 处**（0.70 时母本 5 处／仿写 19 处）。**母本侧非 0 ⇒ 口语本就会"同拍换词"** ⇒ **只作提示项、不拦门、不设硬线**（与 L48/L54c 同一纪律）。43 实跑：`L54 ✓ 零跨集完全重复`／`L54e ✓ 零跨集近重复（≥0.8）｜母本 3 处（本剧 0 处）→ 仅提示`。
  **★★L54e 的“母本查找”必须大小写不敏感（第 71 次尺子校准 · 2026-09-12）**：旧版在项目目录里扫母本用 `_f.endswith(('.txt','.md'))`——**Python 的 `endswith` 区分大小写**，母本一旦命名成 `母本-XX.TXT`（大写扩展名）就**静默跳过**，落到 `else` 分支记“本项未校准（仅提示）”；**更坏的是它只 `print`、没并进 `warns_uncalibrated`** ⇒ **照样打印「✓ 零跨集近重复（≥0.8）」并 exit 0**。**后果：《绣娘不低头》自建剧以来本项从未与母本对照过**，而那个“✓”让人以为校准过了（“跑通但算错”型假绿）。
  修法（四处）：①**显式 `--mother` 优先** ②目录扫描改 `f.lower().endswith(('.txt','.md'))` ③排除派生文件（戏核卡/骨架/报告…）④未校准须并进结论（`warns_uncalibrated`）⇒ 与 L54d/L57 的母本发现**同口径**。
  修后实测：《绣娘不低头》**母本侧 18 处 vs 我方 0 处** ⇒ 本项**真正校准**，且我方比母本更干净。
  **★通用教训：凡“脚本里散落多处母本查找”，必须统一成一个函数/一个口径**——否则修了一处，另一处还在静默降级（与第 61/62/68 次“同一 bug 潜伏多脚本”同源）。
  **★L48 受挫 cue 两套词表必须对齐**（第42轮）：死词表 `PAILIAN` 与结构式 `DEFLATE_CUE` 必须同集；41 漏收 `噎/冷笑/嗤笑/讥讽/语塞/哑口/恼羞/涨红` 八个 → 真吃瘪静默漏计。补词后**两侧同尺子重算**再把新基准写回 `门禁参数.md`。

## ★一键门禁 `素材库/run_gates.py`（唯一入口，2026-09-10 固化）

```bash
python3 素材库/run_gates.py <项目目录> --mother <母本docx或txt> [--relax 19,27,...] [--report 门禁总表.md]
```
六行总表：**①机器门禁（项目内 check*.py）②故事点核销 ③情节分量对标 ④语言层（含 L54/L54b/L54c/**L54d**/**S3a幽灵人物**）④b 命名/连贯/记忆自洽（namecheck.py）⑤台词四功能核销**。④ 行会显式打印 `S3a幽灵人物✓0处／S3b先闻其名N处(提示) ｜ L54跨集重复 ✓｜L54b集内重复 ✓｜L54c同句式 红灯N对/疑似M对`。④b 行会追加 `｜提示项 N：…｜N2-d 场景密度 X.XX/集 = 母本 Y.YY× ✓`（**提示项与相对口径指标都必须在总表显形，不许被"✅通过"埋掉**）。
> **★读总表的顺序＝L1→L4（内容→结构→语言→格式）**，不是表里的行序；**L1 有红不许动 L3/L4**（见上文「唯一检查顺序」）。

**参数可固化在项目内 `门禁参数.md`**（CLI 优先），不必每次手敲：
```
family: 李家=李,刘翠花家=刘,刘家=刘,周婆婆家=周,赵桂芳家=赵
blind: 周婆婆
dead: 春芽娘
villains: 刘翠花,翠花,刘铁蛋,铁蛋,赵桂芳,桂芳,赵石锁,石锁
sweet: 1.47,0.20,41
```
> ⚠ `sweet` 是**母本同尺子实测值**，**改一次词表就要重算一次**（41 补 8 个受挫 cue 后：旧 `1.32,0.20,39` **已作废**，新 `1.47,0.20,41`）。

### ★★它的三个"假绿"陷阱（都在 41 上真实踩到，已修）

### `md2report.py`（`素材库/`｜报告型 markdown → 规整 docx）

`md2report.py <in.md> <out.docx>` —— 与 `md2docx.py`（正文脚本专用）**分工不同**：

**用法**：把多份 md 合并成一个交付件时，**逐份把标题降一级**（`#`→`##`）再加封面，避免 H1 撞车。

## ★全本合并（part 全部写完后收口）三件套

> 适用：一个项目按 part1…partN 写完，要跑"全本 48 集"级别的门禁。
> **为什么必须合并**：③ 情节分量对标、④ L54 跨集重复、④c 的 **σ 与贴线率**——
> **这三项在 part 阶段要么恒"未校准"、要么恒好看**，只有全本合并后才能真判。

### 第 1 件 · 合并正文

```bash
cat 正文part1-E1-E10.md 正文part2-E11-E20.md … 正文partN-….md > 正文全本-<剧名>-E1-E48.md
```

- **前提**：各 part 正文的集标题就是**真实连续集号** `## 第N集`（本剧 part5 首行＝`## 第41集`）
  ⇒ 直接 `cat` 即得全本，**不需要改集号**。
- **校验**：`grep -c '^## 第' 正文全本.md` 必须 ＝ 总集数（48）；再看 `tail -2` 是不是最后一集的完结行。
  **★加强（2026-09-13 补）**：光数个数**不够**——必须**抽集号验连续**：
  `ns = [int(m) for m in re.findall(r'^## 第(\d+)集', t, re.M)]` ⇒ 断言 `sorted(ns) == list(range(1, N+1))`。
  （个数对、号错位/漏集，是"合并脚本静默吞行"的典型形态。）

### 第 2 件 · 合并故事点清单

- 取各 part 清单里 `## 故事点清单` 与 `## 爆点清单` **两段表格**，**机械拼接 + 重连续编号**。
- 脚本**按行解析、不依赖 `#` 唯一**（各 part 的 `#` 都从 1 开始，重复不会漏算；重编号只为便于人读）。
- 头部必须写 **`母本：…`** ／ **`仿写：…`**（**冒号！**）——
  写成「母本《X》＝…」会被 `check_story_points` 判「主线对标未填全」而**整份 ❌**。
- 拼接后必核：**故事点总数 ＝ 各 part 之和**（本剧 620 ＝ 187+…）。

### 第 3 件 · 生成"无 part 标记"的全本 ⑤ 表

```bash
dlgcheck.py "正文全本-….md" --out "05b-台词四功能核销表-<剧名>-全本E1-E48.md"
```

- **表名绝不能带 `partN`**：`run_gates` 靠"正文名有无 part 标记"选表；
  全本正文（无 part）只认**表名也无 part** 的表，否则拿 part 表核全本 ＝ **恒 ❌**。
- **人判回填可 100% 从 part 表继承**（省掉重判 500+ 句）：
  - **句级**：用 **`(集, 台词文本)`** 做键，把各 part 表里"裁定列非空"的结论搬过来；
    ★ 全本零信号句**每一条都在某张 part 表里**（因为判据同源）⇒ 本轮 117/117 全部命中，零重判。
  - **段级**：用 **`(集, 段内句数)`** 做键继承；本轮 39/40，剩 1 段补判。
  - **段级行务必保持 4 列**（`| 集 | 段内句数 | 目的 | 裁定 |`），否则触发坑 ㊽ 真空通过。

### 跑全本门禁

```bash
run_gates.py <项目绝对路径> --copy "正文全本-….md" --mother <母本绝对路径> \
  --checklist "<项目>/50-故事点清单与核销表-….md" --report "<项目>/门禁总表-<剧名>-全本.md"
```

**读全本总表的三个"新面孔"**：
| 道 | part 阶段 | 全本阶段 |
|---|---|---|
| ③ 分量对标 | ⚠ 未校准（part 运行） | **首次可判**（本轮 1.03× 达标） |
| ④ L54 | 只在 part 内比 | **跨 48 集比**（本轮出 1 处·母本同款假红） |
| ④c σ／贴线率 | 常 3/3 过（集少） | **可能转红**（本轮 σ 0.46× 真问题） |

> **一句话**：**part 全绿 ≠ 全本全绿**；全本合并是"交付前最后一道机扫"，
> 出红先按 `ruler-calibration` 坑 ㊾ 做**母本同尺子复核**，再定性真假。

## ★全本合并 · 实战补记 2（2026-09-13 · 选题50《望娣》60 集全本收口）
