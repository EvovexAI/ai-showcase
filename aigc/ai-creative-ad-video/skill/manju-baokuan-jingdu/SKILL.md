# 爆款逐集精读（逐集一句话 ＋ 抽骨架看不见的几处）

## 一 · 什么时候用
- 主编一次投喂 **多部爆款 txt**（每部 50–120 集），要求"认真学、做成素材库、方便以后用"。
- 已有 `00-*` 类的横向总账，但**还没逐集读完**。
- 单部剧需要**深度拆解**（要看到中后段的结构，而不是只拆开局）。

## 二 · 铁律（主编口径，违反＝白做）
1. **口径只拆三样**：**情节 / 矛盾点 / 对白结构是否有意思**。
   **不许纠结字数**（主编原话：「你老是纠结字数！」）。
2. **不许边做边问**：一轮读完就读完，**先做到底再报**（「你能不能拆解完再问我」）。
3. **不许每批停一次等指令**：连续推进（「我都说了继续不要停」）。
4. **不许偷懒**：主编会抽查。**必须留下"每集一句话"这种能被逐条核对的东西**。

## 三 · 落点与命名
```
<工作目录>/学习-爆款拆解/
├── NN-<剧名>-全文.txt              # 抽好的全文（带 series_id/数据抬头）
├── NN-逐集一句话（<剧名>）.md       # ★本工作法的主产物
└── 素材库/
    ├── 00-素材库总目.md             # 分册清单 ＋ 逐集精读进度表
    └── 11-逐集读后新增（…）.md       # 逐集精读后的增量（按批次追加）
```

## 四 · 标准流程

### 步骤 0 · 先看抬头，记数据
每部 txt 开头有 `集数 / 播放量 / 热度 / 点赞 / 收藏 / 评分 / 上线时间 / 出品`。
**记进册子抬头。** ★**收藏/播放比只在样本够大时可用**（播放量几千的剧不可用）。

### 步骤 1 · 建集-行号映射（省 token 的关键）
```bash
grep -n "^第[0-9]*集$" "<file>.txt" | awk -F: '{printf "%s:%s  ", $1, $2}'
```
> ⚠ **有的剧用 `第01集`（补零），有的用 `第1集`**。先 `head` 看一集再 grep。

### 步骤 2 · 逐集读（每轮 10–24 集）
用 Read 带 `offset`/`limit` 按行号区间读。
- **单次读 ≤ 300 行左右**（超了容易把工具撑崩）。
- 读的时候**边读边在脑里写"一句话"**，读完一轮立刻落盘，**不要读完一部才写**。

### 步骤 3 · 写「每集一句话」表
统一表头：

```
| 集 | **一句话** |
|---|---|
| **★E12** | **小标题**：谁做了什么 ⇒ 谁说了哪句关键台词 ⇒ 结果。**钩**＝…… |
```

**一句话的四要素（缺一就是水话）**：
1. **谁跟谁**（人物关系）
2. **争什么**（矛盾点是什么"实物/条件"）
3. **谁赢**（谁把话压住了）
4. **留什么钩**（下一集的引信）

**写法要点**：
- **关键台词必须原文照抄**（带引号），这是日后能直接搬的料。
- **爽点集、转折集、新钩子集**，前缀加 `★`（重要）／`★★`（转折）／`★★★`（全剧最重）。
- **括号里只写必要信息**（`（★全剧第一个大爽点）`），**不要写感想**。
- 长剧按 **"每批 20–30 集"** 分批，一批一张表，批间用 `---` 分隔。

### 步骤 4 · 每批末写「抽骨架看不见的几处」
**这是最值钱的部分。** 只写**在骨架/总账里看不出来的东西**，每条格式：

```
**① ★★<一句判断>**
<原文证据（带引号的原句）>
**⇒ <这条规律怎么用>**
```

**合格的六类发现在**：
| 类 | 例 |
|---|---|
| **刻度** | 这部剧"看得见的刻度"是什么、每几集动一次 |
| **反打/卡法** | 恶人用什么卡主角、主角用什么破 |
| **升级/加码结构** | 同一个动作被用了几轮、每轮加什么压 |
| **转折点的位置与理由** | 第几集转的、靠什么转的 |
| **能看见的物证** | 反复出现、最后被兑现/被毁的那样东西 |
| **声口** | 主角说话的固定口径（几个字、从不抒情等） |

### 步骤 5 · 全剧读完后补「全剧总结」
**六块**：①数据（含数据形态异常提示）②一句话骨架 ③可搬走的手法（5–7 条）④与已读剧的共性 ⑤与本批他剧的分野 ⑥（若文本有硬伤）备查。

### 步骤 6 · 续进素材库
把**增量**写进 `素材库/1N-逐集读后新增（…）.md`，**每条带原文出处**。
写入方向固定为九类：**开局／金句／矛盾点／对白招／恶人招式／打脸与证据／刻度／人物模型／行业真料／收尾**。
最后更新 `00-素材库总目.md` 的**逐集精读进度表**。

## 五 · 必须顺手记的两件事
1. **⚠ 文本硬伤备查（AI 剧通病）**
   - 角色标注混乱（同一角色一部剧里 5–7 个名字：顾秋荷／顾秋珩／秋荷／女主／红衣女子／二儿媳）。
   - **串名事故**：某集的人物列表里出现**别的剧的角色名**（实测：05 E42 出现"吴邪、王胖子"）。
   - **结论**：**分析 AI 剧必须以"内容逻辑"为准，不能信人物标注；我们自己写稿时，台账（信息源/身份/道具/时间线四表）就是为了拦这个。**
2. **⚠ 数据异常要写进抬头**：播放/点赞极低但热度极高 ⇒ 说明"刚上线/靠推荐位"，**收藏播放比不可用**。

## 六 · 不许做的事
- ❌ **不许"只读盘面/目录/标签"就算读过**（**主编 2026-09-22 纠**：*"也就是你没有好好读里面的内容"*）。
  **病根**：我上次读小说时，只读了**字数/章数/字每章、章节目录、写法拆解**，以及第二轮的**七维矩阵**——**那不是读内容，那是读"标签"**。
  **⇒ 铁规：凡"读"的任务，必须逐字/逐集过正文**；盘面数据只能当"抬头"，不能当"读完了"。
  **判据自问**：**这一集里"谁跟谁争了什么、谁说了哪句原话"，我说得出来吗？说不出来＝没读。**
- ❌ 不许只读前 10 集就写"全剧总结"。
- ❌ 不许把"每集一句话"写成剧情复述（要写"争什么/谁赢"）。
- ❌ 不许报字数、报句长（这本工作法**不谈字数**）。
- ❌ 不许拿别部的规律套本部（**每条发现必须带本部的原文出处**）。
- ❌ 不许一次读超过 12 集不分批（工具会崩）。

## 七 · 批量推进顺序（多部时）
按编号顺序推进，**一部结束再开下一部**；中途每部完成后**只更新进度表，不停下来等指令**。
