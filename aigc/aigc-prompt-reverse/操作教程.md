# 1004 · 视频拆解工作台 — 操作教程

> 本教程整合项目 README、EVOFLOW-SETUP 与 EvoFlow 官方机制,是**唯一权威操作手册**。
> 全程分两部分:**A. 独立运行**(不装 EvoFlow 也能用)→ **B. 接入 EvoFlow**(应用+技能+员工+知识库)。

---

## 0. 这个项目是什么(30 秒版)

把一条视频变成**能直接抄作业的拆解报告**(抖音分享链接直达;其他平台视频走 yt-dlp 通道):

```
粘贴分享链接 → 自动下载 → 口播转写(Whisper) → 关键帧截取 → 章节切分
→ 洞察分析(钩子/人群/黄金句/节奏/结构/情绪价值) → Markdown 报告(知识库存档 + 页面可视化)
```

全程本地运行,不上传数据;洞察分析是内置规则引擎,**免费、不调付费模型**。

**三件套在 EvoFlow 里的对应关系**:

| 1004 里的东西 | EvoFlow 里的形态 | 作用 |
|---|---|---|
| `evoflow.extension.json` | 扩展应用(面板侧栏入口) | 一键启动工作台、生命周期托管 |
| `skills/aigc-prompt-reverse/` | 技能(教 AI 操作流水线) | AI 员工替你拆视频 |
| `data/reports/`(Markdown 报告) | 知识库(Vault) | 爆款案例库,写脚本时检索对标 |

## A. 独立运行(3 步)

### A1. 装依赖(只做一次)

- **Python 3.10+**(装时勾选 "Add Python to PATH";本流水线**必须用系统 Python**,不要用任何 venv 里的 Python——venv 缺 pip/librosa 会静默失败)
- **ffmpeg**(下载后把 `bin` 目录加入 PATH)

```powershell
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple --trusted-host pypi.tuna.tsinghua.edu.cn
```

### A2. 启动

双击 **`启动视频分析.bat`**,或在项目根目录:

```powershell
python scripts/web_server.py     # 面板: http://127.0.0.1:8768
```

### A3. 拆第一条视频

1. 浏览器打开 `http://127.0.0.1:8768`
2. 抖音 App「分享 → 复制链接」(文案里必须含 `https://v.douyin.com/xxxx/` 短链,**没有短链先别提交**)
3. 粘贴 → 点「开始拆解」→ 等几分钟(3 分钟视频约 1-3 分钟,首次转写要多等下模型)
4. 完成自动跳详情页;报告同时存两份:
   - `data/reports/YYYY-MM/标题_MMDD_视频ID后6位.md`(知识库,标题在前)
   - `data/videos/{视频ID}/analysis/report.md`(工作副本)

命令行党等价操作:`python scripts/analyze_douyin.py "粘贴文案" --full`

## B. 接入 EvoFlow(5 步)

> 前提:EvoFlow 桌面端已启动。**推荐一键接入**——项目自带幂等脚本,一条命令完成
> B1 扩展注册 + B2 技能装库 + B4 知识库同步,不需要装 `evoflow` CLI(本机 CLI 卡死已绕开):

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-into-evoflow.ps1
```

> 也可**让 EvoFlow 里的 AI 代办**:把 [EVOFLOW-SETUP.md](EVOFLOW-SETUP.md)
> 或 `skills/evoflow-onboarding/SKILL.md` 发给它说「按这个文档帮我完成接入」;
> 下面同时给出每一步的手工路径与验证标准,两种方式任选。

### B1. 安装扩展应用(面板侧栏出现工作台)

**手工路径**:EvoFlow 侧栏「更多 → 扩展应用 → 安装扩展 → 选择本地文件夹」→
选本项目根目录(含 `evoflow.extension.json`)→ 安装。

- 本项目 manifest 是 `link: true`:**不复制目录、只记录路径**,项目挪走/改名后扩展会失效
- 服务是 managed 模式:面板会自动 `python scripts/web_server.py` 启动服务并做 8768 健康检查,
  不需要再手动 A2(但依赖 A1 仍要装好)

**完成标志**:侧栏「扩展」分组出现「视频拆解」,点开是工作台页面 ✅

### B2. 安装技能(教会 AI 操作流水线)

**两条路任选**:

- **一键**:跑上面的 `install-into-evoflow.ps1`,自动把 `skills/` 下
  `aigc-prompt-reverse` + `evoflow-onboarding` 装进技能库
- **让 AI 装**:对 EvoFlow 说「请把本项目 skills 目录下的 aigc-prompt-reverse 安装为 EvoFlow 技能并启用」
- **手工装**:把 `skills/aigc-prompt-reverse/` 整个文件夹复制到 EvoFlow 的技能目录
  (`skills/custom/`,改完即生效)

**完成标志**:技能列表出现 `aigc-prompt-reverse`,状态启用 ✅

### B3. 创建员工(专职拆解师)

1. 「智能体」页创建角色,挂 `aigc-prompt-reverse` 技能
2. 「智能体员工」页 → 雇佣员工:
   - **岗位名称**:视频拆解师
   - **职责**:接收抖音分享链接,调用本地拆解流水线(8768 API)完成拆解,汇报可参考学习的点,并把报告归档进知识库
   - **管辖工作空间**:选本项目目录(报告写在这里)
   - **交接审批策略**:谨慎型(上手推荐)
   - **上班频率**:手动触发即可(拆解是按需任务)

**完成标志**:员工列表出现「视频拆解师」,状态在职 ✅

### B4. 创建知识库(报告案例库)

EvoFlow 知识库是 **Obsidian Vault 模式**(连接本机 Markdown 目录),和本项目的报告格式天作之合:

1. **一键**:跑 `install-into-evoflow.ps1`,自动建/复用「视频拆解报告库」并导入 `data/reports/`(幂等增量)
2. **或手工**:EvoFlow 侧栏「**知识库**」(`#/knowledge/vaults`)→ 新建/连接 Vault
3. 源目录选本项目的 **`data/reports/`**(已有报告全在里面,以后每拆一条自动多一份)
4. 之后 AI 用 `knowledge(action=…)` 工具即可检索,例如:
   「从视频拆解报告库里找几条关于开场钩子的参考案例」

**完成标志**:知识库列表出现该库,搜「钩子」「开场」能命中报告 ✅

### B5. 日常使用(两姿势随时切)

- **让员工拆(推荐)**:复制链接 → 对 EvoFlow 说
  「让视频拆解师拆解这条视频:<链接>」→ 等汇报(速览/可参考学习的点/报告路径)
- **自己看面板**:扩展应用 → 视频拆解 → 粘贴点拆解

报告双写:本地 `data/reports/` + EvoFlow 知识库。

## C. 工作原理(数据流)

```
分享文案(含 v.douyin.com 短链)
   ↓ 8768 /api/analyze(提交 job)
下载视频 → 抽音轨 → Whisper 转写 → ffmpeg 关键帧 → 章节切分
   ↓ 内置规则引擎(免费,无模型调用)
洞察:钩子/人群/黄金句/节奏/结构/情绪价值/对标数据
   ↓
data/videos/{id}/analysis/report.md(工作副本)
data/reports/YYYY-MM/*.md(知识库)→ EvoFlow Vault 检索
```

报告阅读顺序(价值排序):⚡一句话速览 → 🎯可参考学习的点(怎么抄+避坑清单)→
钩子/人群/黄金句 → 节奏/画面/结构公式 → 情绪价值 → 对标数据。

## D. 排错表(高频)

| 症状 | 原因与处理 |
|---|---|
| 提交报 `No Douyin URL found` | 分享文案里没有短链——先找用户/自己补链,别浪费 job |
| 拆解阶段报 librosa/pip 错误 | 用了 venv 的 Python——必须系统 Python 3.12(`py -3.12 scripts/web_server.py`) |
| PowerShell 里 curl 报「参数二义性」 | 用 `curl.exe`(PowerShell 5.1 的 curl 是别名);中文 JSON 先落盘再 `--data-binary @文件` |
| 8768 被占用 | `Get-NetTCPConnection -LocalPort 8768 \| %% { Stop-Process -Id $_.OwningProcess -Force }` 后重启 |
| 扩展装了侧栏没出现 | 确认选的是含 `evoflow.extension.json` 的**根目录**;`link:true` 项目被移动/改名后需重装 |
| 转写有错别字 | Whisper 对专有名词的正常误差,结论以报告分析为准 |
| 拆解要多久 | 3 分钟视频约 1-3 分钟;首次运行多等几分钟下载转写模型 |
