# 1006飞车视频参数约束

1006 走小云雀（Seedance）生视频时按版本定分辨率：C2.0 = 480P，C2.5 = 720P。用户对积分敏感，默认优先用低版本低分辨率小样试跑，确认效果后再提升。一次高版本提交（含已生效任务）会显著消耗积分。
