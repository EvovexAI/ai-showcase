# 1006双参考图生视频

1006 合成飞车视频的标准链路：ffmpeg 从原片截取片段（如 10–15 秒）→ 小云雀生场景图（如夜间高速堵车，需夜景红色尾灯以统一光影）→ Seedance 用「场景图 + 特效锚定截帧(+参考视频)」组合生成。逐秒抽帧用于挑选特效节奏锚定帧。
