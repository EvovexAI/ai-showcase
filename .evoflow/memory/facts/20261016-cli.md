# 小云雀CLI仅沙箱环境可用

pippit-tool-cli（@pippit-dev/cli）实际安装在豆包办公环境的运行时目录 `C:\Users\admin\AppData\Local\Doubao\User Data\sandbox_runtime\bases\<hash>\node\`，系统层 npm 全局和 PATH 都不包含它，普通终端直接敲命令会找不到。想让自建终端可用：把沙箱目录加入用户 PATH，或在系统全局重装（两者都保留账号积分）。网络不稳时可用国内镜像加速。
