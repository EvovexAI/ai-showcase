# 1006小云雀CLI安装位置

pippit-tool-cli（@pippit-dev/cli）实际安装在豆包办公环境的运行时目录：C:\Users\admin\AppData\Local\Doubao\User Data\sandbox_runtime\bases\d0ace100fdff5b2d247847aca1e3d83b\node\，该目录既是 npm 全局根也是 PATH 来源。系统层 npm 全局（C:\Users\admin\AppData\Roaming\npm）与用户 PATH 均不含它。因此该命令只在豆包办公环境内可用，普通终端（Windows Terminal / CMD）直接敲会找不到。若要在自建终端使用，要么把 sandbox 目录加进用户 PATH（复用已有登录凭证），要么另装一份 npm install -g @pippit-dev/cli（需重新浏览器授权）。两条路都保留原积分与账号。
