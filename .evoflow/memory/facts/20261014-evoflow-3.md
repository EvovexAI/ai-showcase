# EvoFlow正式环境路径

技能安装环境必须使用用户正式目录 ~/.evoflow（profiles/default/skills/custom、skills/custom、ui-extensions/registry.json）。~/.evoflow-dev 是作者本机调试目录，用户机器上不存在，脚本和文档均不得写入或探测它，也不能硬编码 D:\dev\github\EvoFlow 下的 venv python。
