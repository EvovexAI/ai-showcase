# EvoFlow系统三大怪癖

实测 EvoFlow 平台侧问题：① evoflow CLI 易卡死超时，需绕开，改用文件直写 + gateway HTTP API；② gateway 实际只读取 ~/.evoflow/profiles/default/skills/custom，与文档不一致，需双目录写入；③ 扩展注册表实际在 ~/.evoflow/ui-extensions/registry.json（文档写的是旧位置）。这些属平台待优化点，不在项目侧改平台代码。
