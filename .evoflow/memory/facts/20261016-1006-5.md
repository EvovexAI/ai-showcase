# 1006低成本试错参数

1006 生成视频低成本试错组合：C2.0 Fast + 480p + 短时长，单条约 60 积分；对比 C2.5 / 1080p 单条可达千余积分。先低成本验证动作与特效，满意后再用 video-super-resolution 超分到 1080p 投放。
