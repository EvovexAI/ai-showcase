# 1004拆解本地视频

feishu_downloads/ai-showcase/self-media/douyin-video-pipeline 拆解入口通常接抖音分享链接，但也可喂本地视频。坑：脚本只认 `video.mp4` 命名，需先建项目目录并把文件改名为 video.mp4。若 venv 损坏，可换系统 Python 运行脚本绕过。产出的报告落在 `data/videos/<视频id>/analysis/report.md`。
