# 特斯拉堵车腾空飞越视频复现

目标：复现原视频「车在堵车流中腾空翻滚飞越」场景。过程：①用 1004 拆解本地视频（踩 video.mp4 命名与 venv 坑）取前段核心动作；②ffmpeg 直接截取片段作参考；③小云雀生夜间高速堵车场景图（红色尾灯长龙统一夜景光影）；④Seedance 参考生成飞车视频。用户多轮纠正：飞车非持续飞行、需翻滚+车底四喷雾+落地喷气、要低分辨率省积分、配音高燃。最终用 C2.0/480P、10 秒片段产出成片。教训：prompt 必须写全动作细节；先用低成本版本小样验证。
