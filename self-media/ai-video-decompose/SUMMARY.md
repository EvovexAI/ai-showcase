## 📱 用户操作流程（3个阶段）

### 第1阶段：首页输入
```
用户在首页输入视频链接 → 选择模型精度 → 点击"🚀 一键拆解"
```
- 输入框：支持视频URL、抖音ID、本地路径
- 模型选择：tiny(快) / base(推荐) / small / medium(准)
- 实时反馈：加载动画显示分析状态

### 第2阶段：列表预览
```
分析完成后，新结果自动出现在列表顶部
```
每个卡片展示：
- 📝 视频标题
- ⏱️ 时长（如：1分30秒）
- 🎬 分镜数（如：15个）
- 📊 字数统计（如：1850字）
- 🎙️ 语音信息（性别/速度）
- 🏷️ 章节标签预览
- ⏰ 创建时间
- 🔘 "查看详情 →" 按钮

**用户交互：**
- 鼠标悬停卡片：高亮 + 阴影变化（提示可点击）
- 点击进入详情页

### 第3阶段：详情页完整展示 + 导出
```
详情页 URL: http://localhost:3002/video-decompose/:id
```

**快速操作栏：**
```
📥 导出：
[脚本(Markdown)] [章节表(JSON)] [分镜表(JSON)]
```

**4个标签页：**

1. **📊 概览**
   - 基础信息卡（标题、时长、分镜数、抖音ID、创建时间）
   - 脚本统计卡（总字数、段落数、平均每段）
   - 语音分析卡（性别、说话速度、是否AI合成）

2. **📝 脚本**
   - 完整的口播脚本文本（可复制）
   - 按段落拆解（显示时间、角色、文本）

3. **📚 章节**
   - 所有章节的卡片展示
   - 每个章节：标号、标题、时间范围、摘要、时长

4. **🎬 分镜**
   - 网格布局展示所有分镜
   - 每个分镜：关键帧截图、编号、时间、视觉类型、时长、对应文本

**脚本标签页：**

- 每个段落的详细信息（时间、角色、文本）

**章节标签页：**
- 视频的章节结构
- 每个章节的摘要描述

**分镜标签页：**
- 所有分镜的关键帧截图
- 每个分镜的视觉信息和对应文本

### 3. 可下载的文档

#### 文档1：脚本 (Markdown 格式)
```
📥 下载链接: GET /api/video-decompose/:id/export/script.md
包含：
- 视频基本信息（标题、时长、字数）
- 语音分析（性别、速度、AI判断）
- 完整脚本文本
- 按段落拆解的脚本
```

#### 文档2：章节表 (JSON 格式)
```
📥 下载链接: GET /api/video-decompose/:id/export/chapters.json
包含：
- 视频标题和时长
- 所有章节的数组
- 每个章节：序号、标题、时间范围、时长、摘要
```

#### 文档3：分镜表 (JSON 格式)
```
📥 下载链接: GET /api/video-decompose/:id/export/scenes.json
包含：
- 视频标题
- 总分镜数
- 每个分镜的详细信息
- 分镜：序号、时间、时长、视觉类型、视觉描述、对应文本
```

## 🎨 界面设计原则

✅ **符合用户习惯**
- 从上到下：输入区 → 历史列表
- 从左到右：卡片信息 → 操作按钮
- 从浏览到深入：列表 → 卡片 → 详情页

✅ **信息层级清晰**
- 大标题 + 粗体：重要信息
- 颜色高亮：数据统计（绿/蓝/橙色）
- 操作按钮：明显色块 + 悬停效果
- 标签页：清晰的视觉分割

✅ **信息密度合理**
- 首页：只显示必要的摘要信息
- 详情页：用标签页组织，避免信息过载
- 每个卡片：图文结合，快速扫描
