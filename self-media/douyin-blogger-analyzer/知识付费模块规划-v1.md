# 知识付费模块规划 v1(讨论稿)

## 〇、地基:EvoFlow 能力 → 课程的映射

| EvoFlow 能力(产品事实) | 对应课程模块 |
|---|---|
| 桌面安装包 + 设置→模型→API Key | 模块一:安装与配置模型 |
| 对话 / Plan / Goal 三模式 | 模块二:使用技巧与实操 |
| 工作空间·代码索引 | 模块二进阶:用 AI 生成项目 |
| 资源市场(资源包/技能/MCP) + 应用中心工作流模板 | 模块三:多场景资源包 |
| Agent Teams·智能体员工(岗位/值班/审批/汇报) + 自我进化·资产中心 | 模块五:AI员工搭建 |
| 沙箱、多账号治理、任务可观测 | 模块四:FDE/面试的实战素材库 |

**结论:5 个模块全部有产品功能直接支撑,不需要"编"课程——每节课都是产品真实功能的展开。**

## 一、模块架构提案(2 条产品线 + 5 个模块)

### 主线:会员订阅(月付/年付)——面向"想学会用 AI"的大盘

**模块一|安装与配置(起步刚需,最先做)**
- 内容:AI 工具全景图 → EvoFlow 安装 → 配置模型(各家 API Key 怎么申请、怎么选) → 常见安装报错 Q&A
- 形态:图文步骤 + 录屏,每个报错一个条目(持续生长)
- 对应你的模块①,受众最广,是所有人的第一课

**模块二|使用技巧与实操(主线核心)**
- 2a 效率实操(普通人):对话技巧 / Plan 模式干正事 / Goal 长任务后台跑 / 让 AI 整理文档、写东西、做表格
- 2b 项目生成(进阶):用 Plan+代码索引 从一句话到一个小项目(个人主页/小工具/小程序)
- 对应你的模块②;2a 服务普通人,2b 服务想进阶的人

**模块三|多场景资源包(会员的核心留存抓手)**
- 内容:按场景打包,每个包 = 指令模板 + 操作步骤 + 举一反三变体 + 交付物示例
- 场景清单(先起 10 个):自媒体内容生产(你已跑通的口播稿审核流水线就是第一个包)、竞品拆解、行程规划、简历优化、家庭采购决策、儿童学习陪伴、小店客服、周报生成、视频拆解、数据整理
- 关键:**这是"每月新增"型资产**——每月 2-3 个新包,会员续费的理由
- 对应你的模块③;资源市场里的工作流模板可以直接分享给会员导入

**模块五|AI员工搭建(差异化王牌,进阶)**
- 内容:岗位设计 → Agent Teams 分工协作 → 值班/审批/汇报 → 自动化与 IM 派发 → 资产中心沉淀经验
- 这是竞品最少、你最有资格教、且产品植入最自然的一块
- 对应你的模块⑤;做完可产出"可展示的成果",和模块四无缝衔接

### 支线:单项高价课——面向求职/职业人群

**模块四|AI 技术面试 + FDE(职业向,后置)**
- 受众:想转 AI 岗、FDE 岗的求职者(和主线人群不同,单独卖)
- 内容:FDE 岗位全景 → 面试考点地图 → 用 EvoFlow 搭 2-3 个写进简历的项目 → 系统设计题拆解 → 模拟面试
- 形态:高价单项课(299-599)或小班,不走月度会员
- 对应你的模块④;放最后做,但它是客单价天花板

### 贯穿权益(不单独算模块)
- 社群答疑(按你清单里的 5 个模块分频道)
- 每月直播答疑(学黎小小的每周节奏,你先每月一次)
- 更新日志:每月新增的资源包/模板清单

## 二、优先级路线图(建议)

| 阶段 | 做什么 | 为什么 |
|---|---|---|
| 现在(0-3000粉) | 模块一 + 模块二a 的免费版公开;模块三先攒 3 个包不发布 | 内容即引流,攒信任 |
| 3000-10000粉 | 会员上线:模块一二三打包(39-69/月);资源包每月+2 | 用免费的"一"和"二a"导流 |
| 10000粉+ | 模块五进阶课上线;模块四小班内测 | 高客单产品,受众已孵化 |

## 三、需要你拍板的 4 个问题

1. **主线人群确认**:模块四(FDE)明显是求职者/开发者向,和"普通人"不重合——同意分两条线(会员主线=普通人效率,FDE=高价单品)吗?
2. **资源包免费:付费比例**:建议 3:7(3 个免费引流,7 个会员专属)?还是全会员?
3. **教学工具绑定度**:模块一二三工具中立(豆包/千问都行),模块五必须用 EvoFlow 教——这个"前中立后绑定"的策略可以吗?
4. **交付形式**:纯文档库 + 录屏(轻,你一个人能跑)vs 加每月直播(重,但留存好)?建议先纯文档+录屏,3000 粉后加直播。
