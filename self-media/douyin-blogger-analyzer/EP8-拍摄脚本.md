# EP8 拍摄脚本《开源第一周,star 涨了 N 个,但有人说我做的是玩具》

> 形式:露脸口播(4 段,合计 <30s)+ 录屏证据(60% 篇幅)
> 总长目标:100~110 秒
> 铁律:所有数字用真实数据,一个都不许编;没有的素材用诚实版替代方案

---

## 分镜脚本

### 段1|0:00-0:05|露脸·立情绪
- **画面**:手机前置,坐在真书桌前,身后代码屏幕虚化,自然光
- **口播**:
  > 「上周有人在我评论区说,我做这个东西——是个玩具。」
- **语气**:平静,不委屈,像在陈述事实

### 段2|0:05-0:12|录屏·引证据
- **画面**:那条质疑评论截图放大(选措辞真实但不脏的;太恶毒就打码)
- **口播**:
  > 「就是这条。(停 1 秒)说实话,那天晚上我确实有点破防。」

### 段3|0:12-0:30|露脸→切录屏·数据回应
- **口播**:
  > 「但破防完,我把这话记下来了。今天开源正好一周,我想用数据回应他。」
- **画面**:切 GitHub 仓库页 → star 曲线推近(数字特写)
- **口播(画外音)**:
  > 「star [真实数] 个,fork [真实数] 个,[真实数] 个 issue,其中 [N] 个不是我提的。」
- **如果数字很小,直接说小**:
  > 「对,才 [N] 个,不多。但每一个都是真的人,亲手点出来的。」
  (小数字+坦然 = 真实感,比硬撑更好)

### 段4|0:30-0:55|录屏·核心演示(全片最重的 25 秒)
- **画面**:挑一条**最流畅的真实任务运行实录**,2 倍速快剪:一句话指令 → AI 员工自动执行 → 交付物出现
- **口播(画外音)**:
  > 「说他玩具的人,可能只看过封面。这是它现在的真实状态:你说一句话,它把活干完。」
- **要点**:只演示一个任务,选"以前必须人做、现在真不用管"的那种;翻车的剪掉,但保留 1 处自然的真实感(光标移动/加载)

### 段5|0:55-1:15|录屏·真实连接
- **画面**:第一个外部 issue / 第一条 PR / 第一个用户部署成功的群聊截图
- **口播**:
  > 「开源第九天,收到了第一个不是我写的 issue。深圳的一个开发者,把它跑起来了,还提了一个我没想到的问题。」
  > 「那一刻我意识到:玩具不玩具,不是他说了算,是用的人说了算。」
- **诚实版(如果还没有外部 issue/PR)**:
  > 「说实话,还没等到第一个外部 issue。但我把文档和 issue 模板都写好了——评论区第一位真跑起来的朋友,我陪你调到通。」
  (真诚是这期的核武器,别编)

### 段6|1:15-1:30|露脸·收尾表态
- **画面**:直视镜头,可以笑一下
- **口播**:
  > 「他可以继续说它是玩具,没关系,我下周继续写代码。」(停顿)
  > 「如果你也在做自己的产品——评论区,交流。」
- **画面收尾**:定格 GitHub 地址字幕卡 2 秒

---

## 素材清单(开拍前备齐)
1. 质疑评论截图 ×1(真实)
2. GitHub star / fork / issue 数字页录屏(可推近)
3. 30 秒最流畅任务演示录屏 ×1
4. 外部 issue / PR / 用户反馈截图(有则用,没有用诚实版)
5. GitHub 地址字幕卡

## 拍摄注意
- 手机前置 1080p 足够;对着窗户自然光,关顶灯
- **声音 > 画面**:安静房间,手机离脸 40cm,有耳机麦就用
- 每段单独拍 3 遍挑 1 条,不用背全稿
- BGM 不加或极轻——回应类内容,安静反而有力量

## Plan B(实在不想露脸)
全程口播+录屏,开头 5 秒改为:**手写便利贴怼镜头**:"有人说我做的是玩具。"+ 手工感素材(纸/白板)。
代价:纪实信任感打折,这条天然弱 20-30%,而且人设的课迟早要补。建议先拍露脸版,拍废 5 条再降级。

## 发布 checklist
- 封面:露脸帧 + 大字「有人说我做的是玩具」
- 置顶评论:GitHub 链接 +「数据都是真的,欢迎提 issue」
- 时间:工作日晚 8-10 点
- 发布后 1 小时内回复每一条评论(冷启动关键动作)
- 数据回填:48h 后录入分析器,对比中位数
