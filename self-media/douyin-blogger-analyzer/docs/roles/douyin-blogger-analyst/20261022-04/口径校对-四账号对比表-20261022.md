## 三、读表要点（对比结论）

1. **发布量最猛、单条最弱**：银泰AI实战 12.3 条/月居首（是对手的 1.7~2.2 倍），但均赞 716、中位 316，与对标账号差一个数量级；爆款率 0%。
2. **中位数比均值更能说明问题**：银泰 均值 716 / 中位 316.5，说明少数几条（9 月后工作台系列）在拉高均值，长尾极低；柱子哥 均值 13233 / 中位 5458，属"稳定高位"而非靠爆款。
3. **涨粉效率决定性指标**：小天fotos 5385 粉/条最高（作品仅 26 条做 14 万粉），银泰 164 粉/条，差 33 倍——问题不在勤奋度，在选题命中率。
4. **时间窗不可忽略**：三位对标账号中两位是 2026-05 后起号（半年做到 6.8~14 万粉），与银泰同期起号（2026-07），可比性高；柱子哥为一年半老号，作上限参考而非同期对标。
