# 知识付费模块规划 v2(修正版:技能中立,面向大众)

## 〇、核心定位(v2 的根本变化)

> **课程教的是"技能",不是某个产品的功能。**
> 技能 = 交给 AI 的一套标准作业程序(Markdown 文件)。
> Codex、ZCode、Workbuddy、Cursor、豆包、千问、EvoFlow——都是技能的"运行环境"。
> 学员学完带走的是能装进任何平台的技能文件;EvoFlow 只是"按需进阶"的推荐之一。

**一个技能包的交付形态(标准规格)**:
```
技能包名/
├── SKILL.md          # 技能本体:name + description + 使用流程(跨平台通用)
├── 使用说明.md        # 各平台怎么装(Codex/ZCode/Cursor/豆包 各一段)
├── 演示视频.mp4       # 真实跑一遍
└── 举一反三.md        # 3 个变体场景
```

## 一、模块结构(5 模块 + 贯穿权益)

### 模块①|主流 AI 工具安装与配置(大众第一课)
- 内容:主流 Agent 平台横评(Codex CLI / ZCode / Workbuddy / 豆包 / 千问 / EvoFlow)→ 每个平台的安装 → 模型配置(API Key 申请、国内可用方案、成本对比)→ 报错 Q&A
- 形态:图文步骤 + 录屏,横向对比表
- 受众:所有人,进付费圈的起点

### 模块②|会用 AI 干活(平台中立的通用方法论)
- 2a 交代任务四要素:角色/目标/约束/验收标准(普通人最缺的就这一课)
- 2b 拆解与迭代:大任务怎么切成 AI 能干的步骤、结果不满意怎么追
- 2c 实操案例:写文案、做表格、整理文件、做攻略——每个案例配"换个工具也这么做"的说明
- 受众:普通人主线

### 模块三|技能资源包(核心资产 + 续费抓手)
- 每包按上面的标准规格交付:**跨平台技能文件**
- 首发清单(从你已跑通的东西里出):
  1. 口播稿多维审核流水线(你已在用,四步审核+修订稿)
  2. 短视频选题库与打分(需求池→多维打分→选题文档)
  3. 竞品/视频拆解报告
  4. 周报/日报生成
  5. 家庭出行规划
  6. 小店 AI 客服话术
- **每月新增 2 个**;免费放 2 个引流,其余会员专属
- EvoFlow 出镜方式:"这套技能在我的工作台里长这样"(演示截图/视频),同时给 Codex/ZCode 的安装说明

### 模块四|FDE 与 AI 技术面试(支线,高价单品)
- 不变:FDE 岗位全景、考点地图、简历项目、系统设计题、模拟面试
- 受众:求职者,单独卖 299-599 或小班

### 模块五|AI 员工搭建(进阶)
- 内容通用化:什么时候需要"员工"而不是"对话" → 岗位设计 → 分工与验收 → 审批与汇报机制
- 演示:主演示用一个大众平台,EvoFlow 作为"完整形态"展示(多员工协作/值班/审批是它的强项)
- 交付:几个"单员工技能包"也是跨平台技能文件

### 贯穿权益
- 社群答疑(按模块分频道)、每月直播答疑、更新日志
