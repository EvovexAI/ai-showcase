## 2️⃣ 分析完成后，列表显示的内容

分析完成后，新结果会自动出现在列表中。每个结果卡片显示：

```
┌─────────────────────────────────────────────────────────────┐
│ 【标题】 抖音热门视频拆解                                    │
│                                                              │
│ ⏱️ 1分30秒 | 🎬 15个分镜 | 📝 1850字 | 💬👩 200字/分钟      │
│ 🆔 1234567890 (抖音ID)                                       │
│                                                              │
│ 【章节预览】                                                 │
│ [开场(5s)] [正文(50s)] [互动(20s)] [结尾(5s)]              │
│                                                              │
│                                  ⏰ 2026-10-12 10:14:52      │
│                                  [查看详情 →]               │
└─────────────────────────────────────────────────────────────┘
```

**卡片显示的信息：**
1. 📝 **视频标题** - 分析得出的视频标题
2. ⏱️ **时长** - 视频总时长
3. 🎬 **分镜数** - 提取的分镜个数
4. 📊 **总字数** - 脚本中的总字数
5. 🎙️ **性别/速度** - 语音分析结果（性别猜测 + 说话速度）
6. 🏷️ **章节标签** - 视频的章节结构预览
7. 🆔 **视频ID** - 抖音ID或"本地视频"
8. ⏰ **创建时间** - 何时分析的
9. 🔘 **查看详情** - 点击进入详情页

**用户交互：**
- 🖱️ 鼠标悬停卡片 → 卡片高亮 + 阴影变化
- 🖱️ 点击卡片任意位置 → 进入详情页

## 📄 产生的文档类型

### 文档1：脚本 (Markdown 格式)

**下载方式：** 详情页中点击 "脚本 (Markdown)" 按钮

**文件名：** `抖音热门视频拆解.md`

**内容包括：**
- 📝 视频基本信息（标题、时长、字数统计）
- 🎙️ 语音分析（性别、说话速度、AI合成判断）
- 📄 完整脚本文本（可直接复制使用）
- 📋 按段落拆解的脚本（带时间和角色信息）

**用途：** 用于视频创作参考、内容编辑、剧本改编

### 文档2：章节表 (JSON 格式)

**下载方式：** 详情页中点击 "章节表 (JSON)" 按钮

**文件名：** `抖音热门视频拆解.json`

**内容结构：**
```json
{

      "index": 0,
```

**用途：** 视频编辑软件导入、时间轴规划、内容分析

## 🚀 现在可以做的事

1. **分析视频**
   - 在首页输入抖音链接/ID/本地路径
   - 选择模型精度
   - 等待分析完成

2. **查看结果**
   - 结果自动出现在列表
   - 卡片显示关键统计数据
   - 点击卡片进入详情页

3. **查看详情**
   - 4个标签页查看不同维度的数据
   - 概览：基础统计信息
   - 脚本：完整口播脚本 + 分段
   - 章节：视频的章节结构
   - 分镜：所有分镜的关键帧

4. **导出文档**
   - 脚本 (Markdown) - 口播稿件
   - 章节表 (JSON) - 内容结构
   - 分镜表 (JSON) - 拍摄计划
